# Cherry-Studio-BB v1.8.0 Release Notes

## 🎯 核心主题：全新【知识库】功能上线（本地 RAG，纯 JS 零编译）

本版本带来了期待已久的 **知识库** 功能：把本地文件/文件夹导入后自动向量化，聊天时一键引用、让 AI 基于你的资料回答，并附原文出处。整套 RAG 引擎（解析 → 切块 → 嵌入 → 混合检索 → 引用）均为**本地 IndexedDB + 纯 JS 实现，零原生编译、文档不出本机**（云端嵌入模型可选，敏感资料可用本地 Ollama）。

---

## ✨ 新功能

### 1. 知识库 TAB（侧边栏新增书本图标入口）
- 创建/管理多个知识库，选择嵌入模型建库（**切换模型自动给推荐参数**，不用自己查模型默认值）
- 老用户启动后自动补入口，无需手动配置

### 2. 文件导入：单个 / 多个 / 整个文件夹
- 【导入】按钮支持一次**多选文件**，也支持**递归导入整个文件夹**（自动跳过不支持格式与重复内容，深 ≤10 层、≤2000 文件防失控）
- 支持格式：`txt / md / mdx / csv / json / pdf / docx / xlsx / xls`（中文 GBK 编码自动识别）

### 3. RAG 引擎（官方成熟路线，本地优先）
- 解析 → 智能切块 → 向量化 → 入库，全程进度可见、失败可重试
- **混合检索**：BM25 关键词（中文分词优化）+ 向量语义双路融合，精确词条和"换种说法"都能命中
- 引用块数、切块大小、重叠度可在**每库设置**中调整（只影响之后新加内容）

### 4. 四栏详情页（专业工作台布局）
`知识库列表 → 文件列表(20%) → 对话查询(30%) → 文件内容(50%)`
- 中间分隔条**可拖拽调比例**，窗口最大化自动按 20/30/50 铺满
- 查询命中列表可点击 → 右侧查看**完整原文**，正文可选中、**一键复制**

### 5. 聊天引用：与网络搜索/MCP 同款原生按键
- 输入栏新增【知识库】按键（书本图标，选中后显示挂载数量角标）
- 点击弹出**与网络搜索/MCP 完全一致的面板弹窗**，多选库、勾选即时生效
- 发送时自动检索并在消息中带上参考资料（**总量封顶 8 块**，防止上下文爆炸），答案有据可查

## 🐛 修复（本版本知识库模块全部审查修复项）

- 修复聊天勾选知识库的时序问题：**勾选即真实生效**，不再有"最后一项漏勾"隐患
- 修复 Node Buffer 池化导致的文件哈希失真与 Word 解析异常
- 修复导入/删除并发竞态：处理中删除的文件不再产生"幽灵"数据
- 修复无扩展名/隐藏文件（`.env`）扩展名识别错误
- 修复聊天引用无总量限制导致的上下文膨胀
- 修复老用户侧边栏不显示新入口的问题

## 📦 下载

⬇️ 请下载 `Cherry-Studio-BB-1.8.0-win-x64-Setup.exe` 安装包。

> 首次使用知识库：先在「设置 → 模型服务」添加一个嵌入模型（本地可用 Ollama 的 `bge-m3` / `nomic-embed-text`，或云端 OpenAI / 硅基流动的 embedding 模型），然后在知识库页新建库 → 导入文件 → 即可在聊天中引用查询。
