# Cherry-Studio-BB v1.6.0 Release Notes

> 版本：1.6.0 · 发布日期：2026-08-22

本次版本聚焦**性能与瘦身**：新增「桌面助手」全局快捷键；全仓清理约 700 行死代码；5 个重组件改为按需加载——首屏 JS 更小、主进程常驻内存更低、安装包更轻。

## ✨ 新功能

### 桌面助手全局快捷键（默认 `Alt + ~`）
- 设置 → 快捷键 新增「桌面助手」条目，与其他快捷键完全一致：**自定义录入、单行重置、清除、启停开关、一键全部重置**。
- 注册为系统级全局快捷键：**主窗口最小化或失焦时，按 `Alt + ~` 依然可以呼出/隐藏桌面助手挂件**。
- 老用户升级后自动出现该条目，无需任何手动操作。

## 🚀 性能优化

### 首屏更快
- Excel 导出库（7.8MB）不再随首页加载——只有真正点击"导出表格"时才动态载入。
- MathJax 数学引擎（体积远大于 KaTeX）只在设置中显式切换到 MathJax 时才加载；默认 KaTeX 用户零感知。

### 内存更低（主进程）
- S3 备份 SDK、Word 导出库（docx）、音乐元数据解析库均改为**使用时才加载**——不用对应功能的用户完全不再为它们付出常驻内存。
- 视频播放改用浏览器原生 `<video>`，移除 react-player 依赖（功能不变，起始时间定位照常生效）。

### 安装包更轻
- 全仓清理约 **700 行死代码**：无引用的 prompt 常量、API 函数、组件、类型守卫、图标、重复启动脚本等。
- 移除 2 个直接依赖、78 个传递依赖（lockfile 层面）。

## 🛡️ 稳定性

- **修复 S3 备份的隐性故障**：此前若 S3 首次连接失败（如网络波动），即使之后网络恢复，备份也会一直报错直到重启应用。现在失败后会自动允许重试。
- 修复一处测试基础设施缺陷与数个 lint 合规问题；测试用例较上一版本净增。

## 🧪 质量

- TypeScript typecheck（node + web + aiCore）零错误。
- 全量测试 **206 文件 / 3582 用例全部通过**。
- oxlint / eslint 零错误（存量 warning 与基线一致，均在未触碰文件）。
- 所有删除项均经全仓库引用扫描二次验证为零引用。

## 📦 下载

- Windows 安装包（NSIS）：`Cherry-Studio-BB-1.6.0-win-x64-setup.exe`
- Windows 便携版（Portable）：`Cherry-Studio-BB-1.6.0-win-x64-portable.exe`

## ⚠️ 已知事项

- 快捷键默认值 `Alt + ~` 若与其他软件冲突，可在 设置 → 快捷键 中自行修改或停用。
- 使用 S3/WebDAV 备份的用户首次执行备份时，S3 组件将按需加载（毫秒级，无感知）。
