# Cherry Studio BB v1.6.1 Release Notes

> 发布日期：2026-08  
> 版本代号：v1.6.1  
> 平台支持：Windows x64 (NSIS 安装包 / 便携版)

---

## 🚀 新增功能与体验升级

### 🎨 1. AI 灵感生图详情页：全新「新话题」支持
- **双入口贴心设计**：
  - 在左侧「生成历史」栏顶部添加了快捷新建话题按键（`+` 图标），随手开启新创意；
  - 在右侧底部操作栏新增「新话题」按键，与 Cherry Studio 整体视觉语言完美契合。
- **独立话题流转与归档**：
  - 点击「新话题」可一键开启全新图片生成话题，自动重置当前输入提示词与已上传参考图；
  - 之前的生图记录与话题无缝归档至左侧历史记录列表，可随时点击回看与切换。
- **快捷键支持**：
  - 支持全局新建话题快捷键联动与 Tooltip 提示。

### 🎵 2. 桌面小助手小窗口：本地音乐「收藏夹」专属模式
- **小窗口新增收藏夹按键**：
  - 在音乐悬浮小窗口的播放控制栏中增设专属「⭐ 收藏夹」模式按键。
- **主程序与小窗口实时同步**：
  - 小窗口与主程序的收藏状态、当前播放模式毫秒级双向同步；
  - 开启收藏夹模式后，上一首、下一首、随机播放与顺序循环均只在收藏曲目中轮播。
- **歌单抽屉智能过滤**：
  - 在收藏夹模式下展开小窗口歌单抽屉，自动过滤仅展示已收藏歌曲，并附带专属「已过滤」高亮徽标和引导提示。

## 🛠️ 代码审查与系统优化

- **通信协议增强**：扩充了主程序与独立小挂件窗口的 `widgetBridge` 通信协议，确保跨窗口状态一致性与响应实时性。
- **全量测试通过**：全量通过 TypeScript 严格类型检查以及 Vitest 自动化测试套件（包含 55 个音乐播放器核心单测与 Paint 模块测试）。
- **保留完整短语生态**：保持全局与助手级快捷短语功能的稳定运行与向前兼容。
