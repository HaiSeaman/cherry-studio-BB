# Cherry-Studio-BB v1.9.3 Release Notes

## 🎯 核心主题：电视播放器交互增强（单击暂停 + 一键关闭）+ 打卡备注功能与图标色板扩容 + 三线审查修复（含 2 个数据级 bug）

本版本补齐电视播放器最后两块体验短板——**点一下就能暂停/继续**、**右上角一键关闭**（彻底解决"打开电视/本地视频后关不掉，只能退出软件"的困扰）；打卡功能上线**备注**（只写两个字说不清的习惯，现在能写清楚具体要求），图标和颜色选择**翻倍还多**；同时完成规范轴/需求轴/过度设计轴三线并行代码审查，修复 2 个数据级 bug 与多处健壮性隐患。

## ✨ 新功能

### 1. 电视页播放器交互增强（IPTV）

- **单击画面 = 暂停 / 继续**：左键点一下暂停，再点一下继续播放（直播与本地视频通用；播放失败时点一下 = 手动重试）
  - 单击延迟 250ms 生效，与**双击全屏**智能消歧：双击不会"顺手暂停"，与腾讯视频 / B 站手感一致
- **右上角 ✕ 关闭按钮**：
  - 点击**彻底关闭**当前播放的视频或 IPTV 电视流——停掉播放引擎、掐断网络下载（不只是暂停，后台不再偷流量），回到"从右侧列表选择频道"的待机画面
  - 直播 / 本地视频 / 连接中 / 失败状态都显示；关闭动作不会误触发暂停或全屏

### 2. 打卡：备注功能（Habits）

- **添加 / 编辑习惯**弹窗新增「备注（可选）」输入框（≤100 字）：写清楚"每天至少 2000ml / 睡前拉伸 10 分钟"这类只看名字猜不到的具体要求
- 备注显示在**三个地方**：
  - **单习惯详情页**：习惯主题色引用式卡片，要点一眼可见
  - **习惯管理列表**：名称右侧灰字显示，过长自动省略，不挤占操作按钮
  - **弹窗实时预览**：填的时候就能看到最终效果
- 留空不占任何存储；填了之后清空保存即真正删掉；**跨设备同步完整携带备注**，且旧设备同步时不抹掉本地已有备注
- 数据库纯追加可选字段，**老数据 / 老备份文件零影响**

### 3. 打卡：图标与颜色选择大幅扩容

- **图标 16 → 40 个**：新增早起 ⏰ / 早睡 🌙 / 戒手机 📵 / 记账 💰 / 游泳 🏊 / 骑行 🚴 / 力量训练 🏋️ / 写日记 📓 / 乐器 🎹 / 绘画 🎨 / 摄影 📷 / 养植物 🌱 / 遛狗 🐕 等，按生活场景排列
- **颜色 10 → 24 个**：按色系排布（红橙 → 金绿 → 青蓝 → 紫粉 → 棕灰），全部中低饱和中间调，浅色 / 深色主题下都清晰
- 全部图标只用 Windows 10 兼容的表情字符（Unicode ≤13），**不会出现"方框豆腐块"**

## 🐛 修复

### 数据级（三线审查发现，逐条人工核实后修复）

- **电视：自动重连"误杀"自愈的流**——信号中断后进入 1~5 秒重连倒计时，若流在等待期自己恢复，残留的定时器到点会把健康的流销毁重启（画面突然重载）。现在播放真正恢复时立即撤销定时器
- **打卡：跨设备同步抹掉备注**——同步数据结构缺备注字段，同步一次本地备注即被清空。已让备注随同步全链路携带，且远端未携带时保留本地值
- **电视：暂停中断流自动重连违背暂停意图**——暂停后直播断流，自动重连会擅自重新起播。现在暂停态断流直接进入"已断开"，等用户回来手动处理
- **打卡：快速连点同一格子可能点错**——读-改-写竞态，已包进数据库事务；电视历史记录裁剪同理
- **打卡：备份导入缺日期校验**——未来日期 / 创建前日期会污染漏卡判定与完成率统计，导入前按"习惯创建日 ~ 今天"窗口拦截

### 健壮性

- 极速连拖两批视频文件触发唯一索引冲突时静默失败且无提示 → 冲突容忍 + 明确报错提示
- 添加 / 编辑习惯保存失败不再静默卡窗，改为弹窗保留 + 错误提示可重试
- 修复 3 个历史遗留坏测试 / 工具链问题（主进程 electron 桩缺失 `app.on` 导致 MCPService 测试全挂、aiCore 一处过时断言、2 处历史 lint 报错）

## 🧹 优化（过度设计审计，净减约 60 行代码）

- 删除无人使用的 `muted` 参数链、`height` 属性、假导出类型等死代码；收回 6 处仅内部使用的导出
- 手写闰年 / 月份天数表改用平台原生能力；两处重复的星期数组、统计模块重复的周几计算收敛为共享实现
- 电视播放器 `play`/`stop` 共用拆卸序列合并为 `teardown()`；导出备份的下载链接延迟回收，防个别环境下载被掐
