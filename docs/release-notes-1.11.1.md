# Cherry-Studio-BB v1.11.1 Release Notes

## 🎯 核心主题：知识库检索链路收口 —— 原文不再灌进对话、引用可溯源、多库公平合并、索引可重建

这一版修的是「知识库」这条链路上长期别扭的地方，**属于修复与打磨**：不新增任何依赖、不改数据库结构、用户数据完全兼容。

**先说主人最有感的那一条**：以前在聊天里挂上知识库提问，回答**之前**会先冒出一大段不是对话的内容 —— 那是检索到的原文。根因是旧实现把原文拼成前缀塞进了**你自己发的那条消息里**，所以它显示在你的气泡中，还会**随历史消息每一轮重发**，越聊越占上下文、又慢又贵。

现在资料改走模型的「系统设定（system）」通道：**你的气泡里只剩你自己的原话**，而且只在**当次提问**生效 —— 不写进历史、不重复发送、不再挤占上下文。

**新增「引用内容」气泡（可溯源）**：命中片段以小药丸形式挂在回答上，点开能看到**文件名 + 原文片段**，再点文件名可**直接打开原文件**。它只用于界面展示与 Markdown 导出，**不会被发给模型**。

**修掉"后面的知识库永远抢不到内容"**：旧实现是「第一个库吃满配额」，同时挂多个库时后面的库等于白挂。现在各库分别检索后**按名次公平合并 + 内容去重**。

**相关性门槛可调**：与提问无关的片段不再被硬塞给模型；**明显相关却召回不到时把它调低（如 0.2）**即可 —— 每个库可独立设置，页面顶部实时显示当前值。

**检索质量两项改进**：切块带上**标题层级上下文**（块文本自带 `手册 > 保修` 这类路径，借用文档自身的标题结构，**零 API 成本**）；配了重排模型时**候选池由 12 扩到 50** 再精排。

**新增「重建索引」**：以前改完切块参数只对**以后新加的文件**生效，而重复导入同一个文件又会被判"内容重复"跳过 —— 等于**没有任何办法刷新老文件**。现在文件抽屉里点一下即可让全部文件按当前参数重切重向量化。

## 🧹 本次改动

### 1. 修复：注入位置错误（回答前先冒出一大段原文）

- 参考资料不再拼接进用户消息正文，改为请求阶段注入 **system 提示**（`attachKnowledgeContext` 单一接缝）
- 用户气泡只显示用户原话；资料**只作用于当次请求**，不进入历史消息、不随轮次重复发送
- 专用图像生成模型（DALL·E / GPT-Image 等）自动跳过检索，不再产生无意义的引用与提示

### 2. 新增：知识库引用溯源气泡

- 助手消息上出现「N 个引用内容」，点开是**文件名 + 命中原文片段**，附复制按钮
- 点文件名**直接打开原文件**（`window.api.file.openPath`）
- 引用数据随消息落库，**重启后仍在**；仅用于界面与 Markdown 导出，**从不发给模型**
- 与联网搜索的引用各自成泡、互不干扰

### 3. 修复：多知识库公平合并 + 跨库去重

- 各库分别检索 → **按名次 RRF 融合** → **内容去重**（同一段内容在多个库里只保留一条）→ 上限 8 块
- 为何按名次而非分数：不同库可绑定不同嵌入模型，**相似度分数不可比、名次可比**

### 4. 新增：相关性门槛（挡住"硬塞资料"）+ 每库可调

- 默认阈值 0.3：语义相似度低于它就不参与结果（关键词路同样受限）
- **向量检索失败时自动降级为纯关键词且不做门槛**，不会把词面命中的内容整体误杀
- 知识库详情页「切块与召回参数」可调（0.05~0.95），顶部徽标显示当前值
- 完全没命中时聊天侧会明确提示，不再静默注入空内容

### 5. 改进：切块带上标题层级上下文（零成本 Contextual Retrieval）

- 按文档自身标题结构给每块加路径前缀（如 `手册 > 保修`），让脱离上下文的片段同时被关键词与向量命中
- 标题块只带父级路径（不重复自己）；没有标题的纯文本完全不受影响

### 6. 改进：重排候选池 12 → 50

- 配了重排模型时先给 50 条候选再精排（未配重排时维持原样，不额外花算力）
- 代价：每次提问发给重排服务的文本变多，**更慢也更贵**，换来更准

### 7. 新增：一键重建索引

- 文件抽屉新增按钮（二次确认 + 实时进度）；按当前切块参数重新处理全部文件
- 原文件已被移动/删除的会单独标为错误，**不影响其余文件**
- 重建后自动清空召回测试结果（旧结果指向的切块已被删除）

### 8. 代码审计后的修复（双轴审查发现）

- 把注入逻辑抽成可测接缝并补 3 个用例 —— 它此前是**唯一零测试的生产路径**（违反 CONTRIBUTING「Features without tests are considered non-existent」）
- 修：召回测试**检索报错时**仍显示"没有达到阈值"的空态（与报错互相矛盾）
- 修：向量检索降级时界面笃定显示 `0.0%` → 改为 `—` 与"相似度：不可用（向量检索降级）"
- 修：改完设置后顶部参数徽标不刷新；窄窗口下徽标换行
- 修：召回页此前显示的是内部融合分（永远 0.1%~3.3% 的假百分比）→ 现在显示真实余弦相似度
- 修既有 bug：引用关联字段名写错（`blockId` → `citationBlockId`）

## ⬆️ 升级说明

- 直接覆盖安装即可，**不需要重新登录、不需要重新配置任何服务商或 API Key**
- **无数据库结构变更**：知识库与聊天记录、助手、模型配置等全部兼容
- 老知识库**开箱即用**：未设置过阈值的库沿用默认 0.3；想吃到新的切块上下文，请在库的文件抽屉点一次「重建索引」（不点也不影响使用，只是老文件的切块保持原样）
- 挂知识库聊天时，回答上方会新增「引用内容」小药丸 —— 这是本版新增的引用溯源，属预期行为
