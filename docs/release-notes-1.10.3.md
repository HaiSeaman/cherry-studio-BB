# Cherry-Studio-BB v1.10.3 Release Notes

## 🎯 核心主题：语音输入加了总开关、快捷键统一为 `Ctrl + \``，小程序不再莫名其妙消失

这一版主要解决两件让你用着别扭的事：

1. **语音输入没法一键关掉** —— 现在设置里加了开关，关掉后按快捷键**真的不会再开麦克风**。
2. **有些小程序找不到了** —— 不是你删的，是应用按"地区"自动隐藏了一批（豆包、通义千问、讯飞星火这些国内应用）。现在**一律全部显示**，不再自动隐藏。

顺带修掉一个挺坑的 bug：语音输入在聊天框里**单打一个反引号 `` ` `` 就会开始录音**（写代码块时尤其容易碰到）。

其余功能（聊天、生图、视频、自动化、打卡、电视、FM 电台、便签闹钟）行为完全不变。

## ✨ 新增与改进

### 1. 语音输入总开关，一键随时关掉

- 位置：**设置 → 默认模型 → 语音输入模型**，服务商下拉框右边新增一个开关
- 关掉之后，按住快捷键**完全不会录音**，麦克风不会被调用（不只是把界面藏起来）
- 这个开关和「设置 → 快捷键 → 语音输入法」的开关是**同一个开关**，两边任意一边改，另一边跟着变，不会出现状态打架
- 关闭时鼠标悬停会提示"已关闭"，界面上的快捷键说明也会同步改口，不会再指着你去做一件已经无效的操作

### 2. 语音输入快捷键统一为 `Ctrl + \``

- 原来的 `Win + Shift + \`` 已从应用里彻底移除，现在统一是 **`Ctrl + \``**
- 如果你之前自己改过语音输入的快捷键，**你的设置会被保留**，不会被覆盖
- 只有从来没改过、还在用旧默认值的用户，这次会自动升级到 `Ctrl + \``

### 3. 修掉了「打个反引号就开始录音」的问题

- 这是个真实存在的 bug：语音输入是靠全局键盘钩子实现的，而它的按键对照表里**没有收录 `CommandOrControl` 这个键名**，导致这个修饰键被悄悄丢掉
- 结果是：原本该是 `Ctrl + \`` 才触发，实际变成**单独按一下反引号就触发录音** —— 在聊天框里写代码块、打 markdown 的时候特别容易误触
- 现在补上了这个键的对照关系，**必须按住 `Ctrl` 再按反引号才会录音**，单打反引号不再有任何反应

### 4. 小程序全部显示，不再按地区隐藏

- 以前应用会按 IP 判断你所在地区，一旦判定为"境外"（包括**挂了代理/VPN**的情况），就会静默隐藏掉 **17 个标记为"仅中国"的小程序**
- 被隐藏的包括：豆包、通义千问、讯飞星火、文心一言、智谱清言、百川、阶跃星辰、海螺、ima、天工、纳米 AI、小艺、WPS AI、知乎直答、商汤、百度 AI 搜索、Minimax
- 表现就是"我没删过，怎么这些小程序不见了" —— **现在不管什么情况，一律全部显示**
- 想不看到哪个，仍然可以在「设置 → 小程序」里把它拖到隐藏区，这个是你的手动操作，不会被自动改动
- 设置页那个「小程序区域筛选」下拉框已移除（它已经没有意义了）

### 5. 「交换」按钮加了二次确认

- 小程序设置页的「交换」按钮以前点了立刻生效、没有任何提示
- 当隐藏区是空的时候点它，结果就是**所有小程序被一次性搬进隐藏区，页面变得空空如也**，很容易让人以为小程序坏了
- 现在会先弹确认框，明确告诉你"将把当前 N 个应用移入隐藏区，M 个放回显示区"，确认后才执行

## ⬆️ 升级说明

- 直接覆盖安装即可，**用户数据与设置完全兼容**，无需任何手动操作
- 升级后请注意两点：
  - 语音输入快捷键变为 **`Ctrl + \``**；如果你自己改过快捷键，以你的设置为准
  - 之前被地区隐藏的小程序会**自动回来**，如果多了你不想要的，去「设置 → 小程序」拖到隐藏区即可
- 不需要重新配置语音识别服务商，密钥与模型设置原样保留
