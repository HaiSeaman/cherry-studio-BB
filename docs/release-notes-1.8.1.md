# Cherry-Studio-BB v1.8.1 Release Notes

## 🎯 核心主题：知识库「三栏式智能工作台」UI 重构 + 重排模型（Rerank）+ 全仓过度工程清理

本版本围绕知识库功能做了**大屏全屏体验重构**与**检索质量升级**：告别旧版四栏挤压与留白，换来满屏自适应的工作台布局；并首次支持**重排模型（Rerank）**，让召回结果的相关性再上一个台阶。同时完成一轮全仓过度工程清理与代码审查修复。

---

## ✨ 新功能与改进

### 1. 知识库详情页彻底重构 —— 现代三栏式智能工作台

旧版四栏布局在大屏最大化时右侧大片留白、文件少时中间空旷难看。新布局充分拥抱大屏：

- **左侧 · 知识库导航**：模型标识、悬停删除确认、一键新建
- **中间 · 主舞台（Flex 自动撑满屏幕）**：「智能语义召回调试工作台」
  - 沉浸式提问框：回车一键检索、Shift+Enter 换行
  - 召回命中卡片：相似度百分比、来源页码/行号定位
  - 全景全文阅读器：大字号 + 1.8 行高，点击卡片即刻展开，选中文本一键复制
- **右侧 · 文档资产抽屉**：导入文件/文件夹、就绪/切块/体积统计胶囊、按文件名实时过滤、紧凑卡片流（格式专属彩色图标 + 处理状态 + 切块数）——无论 1 个文件还是 100 个文件都恰到好处
- 新增**智能检索沙箱引导空态**：展示库模型信息与三步上手指引

### 2. 新功能：重排模型（Rerank）可选

- 在「设置 → 模型服务」添加的重排模型（如 Jina Reranker、Qwen3-Reranker 等），可在**新建知识库**时预选，或随时在**知识库设置**中更换（即时生效，无需重新切块/向量化）
- **检索链路升级**：BM25 + 向量双路 RRF 融合 → 交叉编码精排 → TopK
- 重排失败自动**降级为融合结果**，绝不中断检索；清空选择即可关闭
- 兼容 jina / qwen / cohere / dashscope 等 OpenAI 兼容 `/rerank` 端点

### 3. 工程清理（ponytail 全仓审计）

- 移除 `ky`、`@agentic/searxng` 两个依赖（SearxngProvider 直连 axios，消灭同一文件的 HTTP 客户端混用）
- 删除自研死文件扫描脚本 `scripts/find-dead-files.mjs`
- 清理 `filters.ts`、`MessageWebSearch.tsx` 中残留的注释死代码
