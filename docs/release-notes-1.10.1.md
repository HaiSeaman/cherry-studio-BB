# Cherry-Studio-BB v1.10.1 Release Notes

## 🎯 核心主题：语音输入升级为「边说边出字」+ 更名「语音输入法」+ 全仓审查修复

本版本把语音输入从「按住说话、松开后一次性整段输出」升级为 **说话过程中光标处持续逐字出字**（输入法手感），并且不再借用剪贴板；快捷键设置里该功能更名为「语音输入法」。同时完成一轮全仓代码审查（规范/需求双轴审查 + 主进程/渲染层三区巡检），修复备份恢复与助手状态等 7 处真实缺陷。聊天、生图、视频、自动化、打卡、电视等既有功能行为不变。

---

## ✨ 新增与改进

### 1. 语音输入：说话过程中光标持续出字（不再等松手）

- 按住 `Win + ~` 说话，识别到的文字**随说随出**，一个字一个字往上蹦；服务端对前面说的字做修正时（例如 `你说今天在主` → `你说今天在做些什么东西`），会自动退格改写，光标处始终等于最新识别结果。
- 松开快捷键后只做一次尾部校正，**不会再整段重复输出一遍**。
- 支持的三家识别服务（千问 / 豆包 / 腾讯）全部走实时流式结果；腾讯此前中间结果不上屏的问题一并修复。

### 2. 不再借用剪贴板（真·逐字输入）

- 旧方案是「写入剪贴板 → 模拟 Ctrl+V → 恢复剪贴板」，说话期间你的剪贴板会被反复占用，而且按住 `Win+Shift` 时模拟粘贴会被拼成 `Ctrl+Shift+V`，部分软件不认。
- 新方案直接调用 Windows 系统输入接口（`SendInput`）把字符逐个打进光标：**全程不碰剪贴板**、不受按住的快捷键影响、逐字速度更快。退格修正也改用真实退格键。

### 3. 更名「语音输入法」

- 设置 → 快捷键 中，该功能的显示名从 `voice_input` 改为 **语音输入法**，不再出现英文代号。

### 4. 修复：含 emoji 时的文字回改

- 流式回改时退格次数按「字符」而不是内部编码单位计算。此前若识别结果里含 emoji（占两个编码单元），改写会多退一格、把前一个字也删掉。现在 emoji 按一个字符处理，回改精确。

### 5. 备份 / 恢复链路加固（3 处）

- **路径越界修复**：从 WebDAV / S3 恢复时，若远端返回的备份文件名携带 `../` 之类目录成分，下载的文件会被写到备份目录之外。现在统一剥掉目录成分，只落在备份目录内。
- **不再残留临时文件**：每次从云端恢复后都会清掉下载到本地的备份副本（此前会越堆越多）。
- **失败不再被当成成功**：WebDAV 未初始化等错误此前被当成上传成功返回，现在会正常抛错并提示。

### 6. 修复：助手 / 话题状态两处隐患

- 话题更新改为纯函数式写入，不再就地修改传入对象（此前若传入的是界面正持有的对象，可能触发只读写入错误）。
- 「在历史记录中查看某话题」在话题已被删除时不再生成残缺对象，各调用方都能正确兜底。

### 7. 打包可靠性

- 语音输入所需的系统级原生组件（koffi 的 Windows 预编译绑定）在打包产物中曾缺失，会导致打包版语音输入完全不出字。现在打包阶段会自动把绑定放进应用，并在找不到时**直接报错终止打包**（而不是打出一个坏的版本）。

## ⬆️ 升级说明

- 直接覆盖安装即可，用户数据与设置完全兼容；语音输入的密钥与快捷键配置原样保留。
- 语音输入使用方式不变：**按住 `Win + ~` 说话，边说边看光标处出字，说完松手**。
- 若某个软件对逐字输入不响应（极少数特殊控件），欢迎反馈；可临时在设置里改用其它快捷键组合试试。
