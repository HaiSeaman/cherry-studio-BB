# Cherry-Studio-BB v1.9.4 Release Notes

## 🎯 核心主题：自定义 CSS 全面解锁（内置主题与自定义 CSS 共存）+ 删除跨设备同步 + 全仓审查瘦身

本版本解决一个从主题功能上线起就存在的老大难——**一点内置主题，自定义 CSS 就全部失效**；同时按需移除了跨设备同步功能，完成一轮全仓代码审查与瘦身（净删约 2700 行，依赖零冗余）。内置主题、聊天、打卡、电视播放器等所有功能行为不变。

---

## ✨ 改进与修复

### 1. 主题系统：自定义 CSS 全面解锁

- **修复"点击使用主题后自定义 CSS 被绑死"**：此前只要选中 8 款内置主题中的任意一款（默认"晨间绿洲"除外），自定义 CSS 里的颜色就会被内置主题整体压制而失效。根因是内置主题的 CSS 选择器优先级（特异性）天然高于 cherrycss.com 主题与自定义 CSS 的常规写法。
- **现在的规则简单粗暴**：内置 8 款主题照常一键切换；自定义 CSS / 从 cherrycss.com 复制的主题**永远说了算**——不用改任何写法，粘贴即生效，叠加在所选主题之上。
- 写法提示（与原版 Cherry Studio 一致的历史行为）：自定义颜色请用 `body[theme-mode='light']` / `body[theme-id='sky']` 这类以 `body` 开头的选择器（cherrycss.com 的主题都是这种写法）；`:root` 开头会被主题变量遮蔽。
- 新增主题层叠回归检查脚本（`npm run check:theme-cascade`，6 项断言实测层叠行为），以后改主题配色随手可验。

### 2. 移除跨设备同步功能

- 设置 → 数据设置中的「跨设备同步（便签等）」入口及其全部后台逻辑已按需移除，界面更清爽。
- **不受影响**：窗口之间的状态同步、本地备份 / WebDAV / S3 云备份全部保留，备份功能照常使用。
- 旧数据目录里的同步索引库为无引用残留，不占多少空间，无需处理。

### 3. V2 遗留清理

- 清除 26 个核心文件头部"V2 重构冻结"迁移警告注释（每文件 16-19 行纯注释），删除注释掉的 V2 死代码；本 fork 不跟随上游 V2，只保留当前版本的功能与依赖。

### 4. 全仓审查瘦身（净删约 2700 行，行为零变化）

- **死代码退役**：消息块 6 个零调用类型守卫、3 个无引用 Hook 及配套选择器、十余个 0 引用工具/服务函数、shared 库 6 个死导出与 2 个孤儿常量，全部经引用链逐条核实后移除；
- **集合工具退役**：手写 65 行泛型集合工具 + 268 行专属测试，两个调用点改用已有依赖 lodash 一行等价替换；
- **重复收敛**：画图 / 视频历史两份逐字相同的时间格式化合并为 dayjs 一行；本地备份与 WebDAV 设置页重复的"同步间隔 / 最大备份数 / 管理弹窗"逻辑抽取共享 Hook；
- **脚本与工程**：打包脚本修正名不副实问题并自动化版本号读取（不再每次发版手改）；新增主题回归检查 npm 命令；清理误留的构建日志文件；
- **依赖审计**：全部依赖逐一核对，零冗余、零新增。
