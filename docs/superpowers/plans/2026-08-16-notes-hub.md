# 闹钟便签 Tab 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增「闹钟便签」Tab（/notes）：2×2 四宫格（便签/闹钟/待办/日历），闹钟↔日历共用单一闹钟数据源，便签/待办/日历当日待办三者数据独立。

**Architecture:** 全渲染层实现（React + Dexie + Redux persist + Web Audio 合成铃声），主进程仅新增 Window_Focus IPC；UI 复用音乐页晨间绿洲 mx 主题。

**Tech Stack:** React 19, Dexie v12, Redux Toolkit, Web Audio API, react-markdown+dompurify, styled-components, vitest。

**Spec:** `docs/superpowers/specs/2026-08-16-notes-hub-design.md`

## Global Constraints

- 不做小纸条独立窗口；待办 ✕ = 轻确认后永久删（无垃圾桶）；便签 ✕ 进垃圾桶。
- 闹钟单一数据源：日历闹钟 = 带 `date: 'YYYY-MM-DD'` 的闹钟；调度含 90 秒补触发窗口、跨天重置、lastTriggerKey 防重。
- 响铃：系统通知 + 持续响到手动停 + `document.hidden` 时 `window.api.window.focus()`。
- UI 全部走 mx 晨间绿洲浅色（`pages/notes/components/mx.tsx` re-export `pages/music/components/mx`）；prefers-reduced-motion 降级。
- 每次提交只 add 本计划文件；测试命令 `npx vitest run --project renderer <路径>`；类型检查 `npm run typecheck:web / :node`。
- Redux persist version 214→215（追加 'notes' 图标）；Dexie v11→v12。

export type AlarmSoundType = 'default'|'apple'|'android'|'nokia'|'crystal'|'bird'|'electronic'

  stop(): void
  setVolume(percent: number): void    // 0-300 → masterGain 0-3
  isRinging(): boolean
  preview(type: AlarmSoundType): void // 点选铃声时试听 1.5 秒自动停

// useAlarmEngine()（NotesPage 顶层挂一次；useLiveQuery 取 hub_alarms）
export function useAlarmEngine(alarms: HubAlarm[]) {
  return {
    now: Date,                 // 每秒刷新的当前时间（时钟显示用）
    ringing: HubAlarm | null,  // 正在响的闹钟（含倒计时结束的伪闹钟 {label, sound}）
    stopRinging(): void,
    fireExternal(label: string, sound: string): void  // 倒计时结束调用
  }
}
// 内部：useEffect 1s interval → computeDueAlarms → 命中：alarmSounds.start(sound) + new Notification('闹钟响铃', {body, silent:true}) + document.hidden 时 window.api.window.focus() + db 更新 triggered/lastTriggerKey；crossedDay → 清全部 triggered；响铃状态存本 hook（localStorage 不需要，闹钟持久化在 Dexie）

// useCountdown(onFinish)
export function useCountdown(onFinish: () => void) {
  return {
    remainSec, totalSec, running: boolean,
    start(h: number, m: number, s: number): void,  // 时间戳法 timerEndTs
    pause(): void, resume(): void, reset(): void
  }
}
