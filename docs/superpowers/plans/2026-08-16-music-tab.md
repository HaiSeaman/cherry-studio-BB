# 音乐 Tab 页实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Cherry Studio BB 中新增「音乐」Tab 页：左栏本地音乐播放器 + 右栏 FM 网络电台，功能与 UI 复刻 `音乐tab页.md`，按 BB 架构（React 19 + Redux + Dexie + antd + styled-components）重写。

**Architecture:** 渲染层单页面 `/music`（懒加载）双栏布局；共享 `audioEngine` 单例（一个 `<audio>`，本地/FM 互斥）；FM API 由渲染层直连 radio-browser（镜像随机+容灾+归一化过滤去重全部复刻）；本地元数据由主进程新 `MusicService`（music-metadata）解析，封面/缩略图落 `userData/music/covers`；持久化 = Dexie 三张新表 + Redux persist 新 slice。

**Tech Stack:** React 19, Redux Toolkit + redux-persist, Dexie, styled-components, antd 5, lucide-react, music-metadata@^7.14.0（主进程）, vitest（renderer 项目, jsdom）。

**Spec:** `docs/superpowers/specs/2026-08-16-music-tab-design.md`

## Global Constraints

- 不引入 Howler；播放内核为原生 `<audio>` 单例。
- 不移植 `musicfile://` 协议与路径白名单；本地文件用 `file://` URL 直播。
- FM 所有端点、镜像、归一化截断、过滤（剔除 HLS/M3U8、bitrate<64）、url 去重、内置 4 个 RTHK、合并顺序（中港→自定义→线上）、7 天缓存语义照 `音乐tab页.md` §7 复刻。
- 新依赖仅 `music-metadata@^7.14.0`（主进程用，装 devDependencies 即可——本 fork 运行时依赖都在 devDependencies）。
- CSP `media-src` 必须扩为 `'self' file: blob: http: https:`。
- Redux persist version 213→214（老用户追加 music 侧边栏图标，照 v213 paint 模式）；新 Dexie `db.version(11)`。
- 样式全部用 BB CSS 变量（`--color-*`，见 `src/renderer/src/assets/styles/color.css`），自动适配明暗主题；图标 lucide-react。
- 用户仓库有未提交改动：**每次 commit 只 add 本计划新增/修改的文件，绝不 `git add -A`**。
- 包管理器 pnpm；测试跑 renderer 项目：`npx vitest run --project renderer <路径>`。
