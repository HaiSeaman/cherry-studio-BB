# Release Notes - v1.6.2

## 🌟 核心新特性

### 1. 全新「动感视频助手」（video_gen）
- **独立助手形态**：在对话、生图、自动化之后，推出第四种专属助手形态，拥有独立的「会话历史 - 消息流 - 参数控制栏」工作区。
- **主流视频模型接入**：
  - **阿里云百炼 (DashScope)**：原生支持通义万相 Wan2.1 / Wan2.0 视频生成模型（文生视频、图生视频）。
  - **火山引擎 (Ark/豆包)**：支持 ByteDance Seedance 视频生成模型及参数指令自动化注入。
  - **腾讯混元 (Hunyuan)**：内置原生 TC3-HMAC-SHA256 签名鉴权算法，支持混元视频生成。
- **双模生成支持**：
  - **文生视频 (Text-to-Video)**：支持设置提示词、时长（5s/10s）、分辨率（480P/720P/1080P）、画面比例。
  - **图生视频 (Image-to-Video)**：支持上传首帧参考图，配合运动描述生成动态视频。
- **任务状态与持久化体系**：
  - **真实状态流转**：实时展示「排队中」与「生成中 (已耗时)」状态，绝不伪造虚假进度。
  - **防失效持久化存储**：云端视频链接（通常 24 小时过期）生成后自动下载并持久化转存至本地 `FileManager`。

### 2. 生成文件自动保存与路径配置
- **生成图片/视频保存路径**：在「设置 - 数据设置」中全面升级保存路径配置，支持选择本地专属文件夹。
- **双轨存储逻辑**：
  - 未配置本地目录时：默认保存至内部安全缓存数据文件夹，历史会话长期可访问。
  - 配置本地目录后：生成完成时自动、静默复制一份至本地指定目录，告别弹窗打扰。

### 3. 常规通知设置升级
- **动感视频通知**：在「设置 - 常规设置 - 通知设置」中新增动感视频助手专属通知开关与自定义提示音选项。
