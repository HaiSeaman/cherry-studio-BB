# Cherry-Studio-BB v1.7.2 Release Notes

## 🎯 核心主题：打卡 TAB「自然年统计」新模块 · 打卡页排版与 UI 重设计 · 全仓代码审计加固

本次版本为**打卡（Habit Tracker）功能页**带来两项实质性提升：全新的「自然年统计」年度视图，以及整页排版与视觉语言的重新对齐；同时对全仓代码进行了一轮严格审计，修复了若干真实缺陷（含一处 React Hooks 规则违规与一处 memo 失效），静态检查从 5 处警告收敛到 0。

---

## ✨ 新增功能：打卡「自然年统计」模块

在打卡 TAB 的**统计视图**中新增【自然年统计】内容框，用于回答一个具体问题：**某个习惯在某个自然年（2025 / 2026…）里到底打卡了多少天？**

```
【自然年统计】  ‹ 2026年 ›                    共打卡 6 天
  [🚭 戒烟] [💧 喝水] [🏃 运动] …
  ┌──────────────────────────────────────────────┐
  │  整年 365/366 天热力图（打卡日深色）           │
  └──────────────────────────────────────────────┘
  完成率 62.5% · 已过 241 天（跳过 3 天不计）
```

- **年份切换**：`‹ 2026年 ›`，可选范围 = 习惯创建年 → 今年（今年默认，边界自动禁用按钮）
- **习惯 chips**：按习惯顺序排列，点击即切换该习惯的年度热力图与打卡天数
- **整年热力图**：GitHub 风格周列网格，铺满一整个自然年
  - **打卡** = 习惯主题色深格；**跳过** = 同色浅格；**未打卡** = 空白；**今天** 额外描边
  - 鼠标悬停显示具体日期与状态，例如「8月2日 · 已打卡」
- **未满年按今天截断**：如 8 月 29 日查看 2026 年，统计区间为 1/1~8/29（共 241 天），不会把未来天数算进分母；完成率沿用既有口径——**跳过日不算应打卡日**
- **口径统一收口**：新增纯函数 `yearWindow` / `yearlyCheckinStats` / `yearlyHeatCells`（`pages/habits/services/stats.ts`），组件禁止自行实现统计口径

> 原「年度热力图」模块（多习惯完成率视图）因与本次模块定位重复，已按需求移除。

## 🎨 打卡页排版与 UI 重设计

- **趋势图重做**：原先是一根没有任何参照的裸折线，现升级为**渐变面积填充 + 25/50/75 参考虚线 + 当日完成率标注**
- **完成率对比条补表头**：新增「习惯 / 完成率 / 强度」三列表头，解决强度指数列此前是裸数字、无说明的问题
- **文字排版成体系**：区块标题统一 eyebrow 风格（12px / 600 / 字距 / 弱化色），大数字统一行高与等宽数字（tabular-nums），标签统一字距
- **防挤压修复**：
  - 指标卡 `repeat(4, 1fr)` → `repeat(4, minmax(0, 1fr))`，窄窗口不再溢出
  - 热力图格子设 14px 最小宽度 + 横向滚动，解决 53 列在窄窗被压成细丝的问题
- **细节打磨**：返回按钮胶囊化、月份标题两段式（年份小字弱化 + 月份大字强调）、「回到今天」仅在查看非当前月时显示、星期分布图卡片化并加 100% 基准虚线、习惯管理列表色点前置（色 → 图标 → 名称的阅读动线）

## 🛡️ 全仓代码审计加固

按严格 review 流程对全仓做了正确性 / 安全 / 性能 / 死代码 / 无用依赖审计，修复并验证了以下内容：

| 问题 | 说明与修复 |
|---|---|
| **React Hooks 规则违规** | 热力图 memo 化时一度将 `useMemo` 置于条件 return 之后，二次审查中自抓并修正为全部 hooks 无条件调用 |
| **memo 失效（性能）** | `allRecords.get(id) ?? { 新建 Set }` 每次渲染产生新对象，导致依赖它的 useMemo 每帧重建 366 格 → 改为模块级 `EMPTY_SETS` 单例 |
| **浮空 Promise ×2** | `ShortcutService` 截图快捷键补 `void`；`scripts/screenshot-smoke.js` 补 `.catch` 拒绝处理 |
| **lint 配置根因修复** | `no-unused-vars` 开启 `varsIgnorePattern`/`argsIgnorePattern: '^_'`（下划线前缀 = 有意忽略，代码库既有约定），消除 3 处误报 |
| 死代码 | 清理死导出 `monthTitle`（连带测试） |

**核查后确认无问题（避免重复怀疑）**：10 个运行时依赖全部在用（ripgrep 走构建期二进制，pdf-parse / officeparser / jsdom 走动态 import）；无死文件；定时器与事件监听均有正确清理；Dexie v13 打卡两表结构与索引正确；habitService 打卡状态机（打卡 / 取消 / 跳过 / 撤销）与实现一致。

## 📦 安装与升级

Windows 64 位用户请下载下列任一产物覆盖安装，数据自动保留：

- `Cherry-Studio-BB-1.7.2-x64-setup.exe`（安装版，推荐）
- `Cherry-Studio-BB-1.7.2-x64-portable.exe`（便携版，免安装）

- 首次进入**打卡**页请点右上角「添加习惯」创建习惯（如 🚭 戒烟 / 💧 喝水 / 🏃 运动）
- 月历左键打卡或取消，右键标记跳过（跳过不断卡），点击习惯名进入单习惯详情
- 统计视图底部即为本次新增的【自然年统计】模块
