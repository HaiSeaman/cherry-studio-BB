# Cherry-Studio-BB v1.7.0 Release Notes

## 🎉 重点新特性：全新「习惯打卡（Habit Tracker）」TAB 工作台

1.7.0 版本正式上线全新的独立「习惯打卡」工作台，结合极简高效的交互与科学的习惯养成模型，帮助你专注每日习惯养成与长期自律追踪！

---

### 🌟 核心功能一览

#### 1. 📅 月历全屏横排矩阵
- **沉浸式月度看板**：采用直观的横排矩阵布局，左侧习惯列表、中间 1~31 号全月打卡格、右侧连续天数与操作。
- **自适应拉伸**：CSS Grid 智能响应式重构，在全屏及最大化窗口下均匀等宽铺满屏幕，不变形、不拥挤。
- **今天高亮竖带**：视觉焦点贯穿表头与所有打卡格，一眼锁定当日任务。
- **周末与漏卡细节**：周末日期微灰区分、漏卡柔和虚线警示（告别纯红压迫感）、当前连续达标点亮 🔥 火苗徽标。

#### 2. ⚡ 便捷打卡与贴心容错
- **极速交互**：左键单击直接打卡/取消打卡。
- **跳过机制（Skip）**：右键菜单支持将当日标记为「跳过」（灰色横杠），适合生病、出差、特殊假期，**不断卡、不扣分**。
- **5 秒撤销防手抖**：误取消打卡时弹出通知气泡，带 5 秒一键撤销按钮，防止辛苦维持的连续天数误删。

#### 3. 🧠 科学的习惯强度指数 (EMA)
- 告别传统打卡「断一天立即清零」带来的挫败感！
- 采用指数移动平均算法（EMA，约 13 天半衰期，匹配 66 天习惯养成规律），按最近的打卡频率平滑衰减，科学量化习惯稳固程度。

#### 4. 📊 深度统计与 365 天全景热力图
- **统计卡片**：今日打卡进度（带动态进度条）、当前连续天数、本月总体完成率、历史最佳记录。
- **习惯详情面板**：单项习惯完成率、强度指数、星期偏好柱状分布图。
- **365 天弹性热力图**：自适应拉伸铺满容器，周对齐月份标签与 5 级色阶图例，全览全年的努力轨迹。

#### 5. 🛠️ 习惯管理与数据安全
- **习惯管理中心**：支持随时编辑、归档暂时停用的习惯、彻底删除（带二次安全确认）。
- **实时表单预览**：新建/修改习惯时，图标、颜色与名称所见即所得。
- **防重复提交锁**：防止回车或连击生成重复项目。
- **数据逃生舱**：支持一键导出与导入全量 JSON 备份，本地 IndexedDB 数据随心迁移。

---

### 🔧 架构与稳定性改进
- **Dexie v13 本地数据库**：无缝升级，自动建立 `habits` 和 `habit_records` 两张独立数据表，现有便签、闹钟、音乐、聊天数据 100% 完好无损。
- **响应式状态流**：打卡状态采用 `useLiveQuery` 监听，所有视图、卡片与热力图毫秒级自动联动更新。
- **全量测试守卫**：全量 2890+ 个单元测试与 TypeScript 类型检查 100% 通过。
