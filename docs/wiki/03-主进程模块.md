### 2.6 全局语音输入（voiceInput/，v1.10.0 新增 / v1.10.1 流式重构）

`ShortcutService` 对 `voice_input` 走特殊分支：`registerShortcuts`/`unregisterAllShortcuts` 都会把该配置 `sync` 给键盘钩子管理器（不走 globalShortcut——需感知 keyup，且禁用/清空快捷键时也要同步停止）。

| 模块 | 文件 | 职责 |
|---|---|---|
| **VoiceInputService** | `voiceInput/VoiceInputService.ts` | 主进程编排：键盘钩子 start(holdKeys) → 按所选服务商建识别会话；渲染推音频 → 转发；**云端每次返回「累计全量」文本 → `StreamingTypewriter.commit()` 差量上屏**；渲染 finalize → 等最终文本后只做尾部校正（不整段重复输入）。`finalize` 的 finally 里 `endSession()` 收尾 |
| **StreamingTypewriter** | `voiceInput/streamingTypewriter.ts` | 增量打字器：维护「已打进光标的文本」，收到最新全量文本时求最长公共前缀（`commonPrefixLength` 对代理对切点回退一位，防把 emoji 拆成半个码元）→ 退格删分叉尾巴 → 只输入新增片段；`freeze()` 后只追加不退格（焦点漂移保护）。**退格次数按码点计（`[...str].length`），不能用 `str.length`（UTF-16 码元），否则含 emoji 会多退一个字** |
| **textInserter** | `voiceInput/textInserter.ts` | 全局逐字输入：koffi 调 `user32!SendInput`——字符走 `KEYEVENTF_UNICODE`（WM_CHAR 通道，不受物理按住的 Win/Shift 影响，旧剪贴板方案按住说话时 Ctrl+V 会被污染成 Ctrl+Shift+V），退格用真实 VK_BACK。导出 `buildUnicodeRecords/buildBackspaceRecords`（x64 INPUT 40 字节布局）与 `getLastInjectionAt()`；FFI 加载失败仅记日志不抛（降级而非崩溃）。**v1.10.1 起不再使用剪贴板 + Ctrl+V** |
| **focusGuard** | `voiceInput/focusGuard.ts` | 焦点漂移守卫：录音期间监听全局 keydown/mousedown，检测到用户真实输入 → `typewriter.freeze()`（宁可少改字也不删错地方）。长按自动重复用「holdKeys + 自维护 pressed Set」排除；自身注入的键鼠事件用 120ms 回声窗口（`getLastInjectionAt`）排除 |
| **keyboardHook / pressHoldDetector** | `voiceInput/*.ts` | uiohook-napi 全局按下/松开 + 防抖（start 20ms / stop 50ms）输出 start/stop；检测器与键盘库解耦（事件以抽象 `KeyEventLike` 输入，便于单测） |
| **ASR 适配器** | `voiceInput/asr/{qwen,doubao,tencent,index}.ts` | 千问（dashscope duplex：run-task → result-generated → finish-task，`applySentence` 合并已结束分句 + 当前分句）、豆包大模型流式（`/api/v3/sauc/bigmodel` 4 字节帧协议，`result.text` 累计全量）、腾讯云（HMAC-SHA1 签名 URL，`slice_type` 2 落盘、0/1 仅实时预览）。**适配器契约：`onResult` 必须是累计全量文本** |
| **voiceKeyboardManager** | `voiceInput/voiceKeyboardManager.ts` | 键盘钩子单例：`sync(shortcut)` 幂等（启用且有快捷键 → 启动钩子，否则停止），并记住 `parseShortcutToKeycodes` 出的键码传给 `VoiceInputService.start(holdKeys)` |

**打字链路**：`keyboardHook`(按住) → `VoiceInputService.start(holdKeys)` → 渲染层推 16k PCM → 适配器 `onResult`（累计全量）→ `StreamingTypewriter.commit()`（前缀差量 + 退格修正）→ `textInserter` 逐字 SendInput → 松开 → `finalize()` 校正尾部 → `endSession()`。

**打包注意（koffi）**：见 [08 文档 §4](./08-构建运行与测试.md)。

## 3. 内置 MCP Server（src/main/mcpServers)

工厂 `factory.ts:createInMemoryMCPServer(name, args, envs):19` 按 `BuiltinMCPServerNames`（定义于 `src/renderer/src/types/index.ts:636`，形如 `@cherry/memory`）分发，共 9 个标准 MCP `Server` 实现 —— 内置 server 免起子进程，由 MCPService 直接 in-memory 使用：

| Server | 文件 | 功能 |
|---|---|---|
| memory (`@cherry/memory`) | `memory.ts:328 MemoryServer` | 本地知识图谱记忆：create/delete_entities、relations、add_observations、read_graph、search_nodes、open_nodes |
| sequentialthinking | `sequentialthinking.ts:146` | 结构化逐步推理工具 |
| brave-search | `brave-search.ts` | Brave 网页搜索 `brave_web_search` / `brave_local_search`（需 BRAVE_API_KEY） |
| fetch | `fetch.ts` | URL → Markdown 网页抓取（30s 超时保护，防超慢/恶意站点挂住） |
| filesystem | `filesystem/server.ts + tools/` | 受限沙箱文件操作 read/write/edit/ls/glob/grep/delete（baseDir 由 args/envs 解析） |
| dify-knowledge | `dify-knowledge.ts` | Dify 知识库检索（需 DIFY_KEY） |
| didi-mcp | `didi-mcp.ts` | 滴滴出行：地图搜索/估价/订单/司机追踪（仅中国大陆；HTTPS + header 传 key + 30s 超时） |
| browser | `browser/controller.ts CdpBrowserController` | CDP 浏览器控制：open/execute(JS)/screenshot(30s 超时)/snapshot/tabs/reset；普通(持久)/隐私(临时)两种模式；设 `setWindowOpenHandler` |
| hub | `hub/` | 元服务器：聚合所有活动 MCP 工具，暴露 meta-tools `list`（搜索）/`inspect`(JSDoc stub)/`invoke`(调用)/`exec`（vm 沙箱多工具编排，worker.ts 含原型链逃逸防护；**worker 源码必须保持纯 JS，禁止 TS 语法**）；`hub/toolname.ts` 做 camelCase 工具名映射去重 |
