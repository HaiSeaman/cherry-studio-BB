# 04 · 渲染进程模块（src/renderer）

## 1. 应用入口与路由

### 入口链

- **`entryPoint.tsx`**：导入全局样式（index.css / tailwind.css）、Antd v5 对 React 19 的 patch、dayjs 中文 locale；`createRoot` 挂载 `<App />`。i18n 已移除，固定中文。
- **`App.tsx:35`** Provider 嵌套树（自外向内）：
  ```
  Redux Provider → QueryClientProvider(@tanstack/react-query, staleTime=5min)
  → StyleSheetManager(styled-components) → ThemeProvider → AntdProvider
  → NotificationProvider → CodeStyleProvider → PersistGate(redux-persist)
  → TopViewContainer(全局弹层) → Router
  ```
  顶层副作用：`initWidgetBridge()`（音乐挂件消息桥，模块级幂等）与 `useAutomationRunner()`（监听主进程自动化任务触发）。
- **`Router.tsx:20`**：`HashRouter` + react-router-dom v6 `<Routes>`；未完成 onboarding 时先渲染 `<OnboardingPage>`。

### 路由表

| 路径 | 页面 | 说明 |
|---|---|---|
| `/` | HomePage | 聊天/助手工作台，首屏同步加载 |
| `/apps/:appId`、`/apps` | MinAppPage / MinAppsPage | 内嵌网页小程序 |
| `/notes` | NotesPage | 闹钟便签中控台 |
| `/habits` | HabitsPage | 打卡（习惯追踪 TAB），懒加载：月历打卡 / 统计 / 习惯管理 |
| `/settings/*` | SettingsPage | 设置页 |
| `/launchpad` | LaunchpadPage | 启动台（功能入口聚合） |

非首屏页面 `lazy()` 懒加载，外层 `<ErrorBoundary>` + `<Suspense>`；同层渲染全局 `Sidebar` 与 `NavigationHandler`（`handler/NavigationHandler.tsx:7`：注册全局快捷键 + 监听主进程 IPC 导航，渲染为 null 的逻辑组件）。

> 已下线路由：独立 `/music`、`/paint`（功能分别并入 notes 中控台与 HomePage 工作区，服务保留）。

## 3. 服务层（services）

多为具名导出函数或单例类：

- **`ApiService.ts`** — AI 请求总入口：`fetchChatCompletion:185`(对话流式补全)、`fetchImageGeneration:327`、`fetchMessagesSummary:418`(标题摘要)、`fetchGenerate`、`fetchModels/checkApi:709/checkModel`(连通性检测)、`getRotatedApiKey:611`(API Key 轮换)、`fetchMcpTools`。
- **`messageStreaming/`** — 流式响应处理：`BlockManager.ts`、`streamingTextProjection.ts`(平滑输出)、`callbacks/`(各 ChunkType 回调) + `StreamProcessingService.ts`。
- 数据/持久化：`FileManager.ts`、`ImageStorage.ts`、`BackupService.ts`、`db/`、`import/`。
- UI 支撑：`ShikiStreamService/ShikiStreamTokenizer`（代码高亮流式 token 化，配合 worker）、`NotificationService`、`ImagePreviewService`、`NavigationService`、`TabsService`、`PasteService`、`EventService`(EventEmitter 总线 EVENT_NAMES)、`LoggerService`、`TokenService`(token 计数)、`WebSearchService`、`TranslateService`、`AssistantService`、`ConversationService`、`HealthCheckService`、`StoreSyncService`、`QuickPhraseService`、`defaultAssistant.ts`。
- 其他关键：`MessagesService.ts` — `getUserMessage:96/getAssistantMessage:166/isGenerating:68/checkRateLimit:235`。
- `providers/WebSearchProvider/` — 各搜索服务商抽象与实现（注意：与 React Provider 无关）。

## 4. Hooks / Context / Handler

- **`hooks/`**（40+）：领域 hook `useAssistant/useTopic/useMessageOperations`(17KB 消息 CRUD)/`useModel/useProvider/useMCPServers/useMinapps/useTranslate/useWebSearchProviders/useSettings/useShortcut(s)/useOnboardingState`；基础设施 `useAppInit/useBridge/useSmoothStream/useTextareaResize/useDrag/useTimer`。
- **`context/`**：React Context 集 —— ThemeProvider、AntdProvider(ConfigProvider/locale)、NotificationProvider、CodeStyleProvider(代码样式)、StyleSheetManager、MessageEditingContext。
- **`handler/`**：仅 NavigationHandler。
- **`workers/shiki-stream.worker.ts`**：Shiki 高亮 worker。
- **`queue/NotificationQueue.ts`**：通知队列。

## 5. aiCore 包装层（详见 05 文档）

`aiCore/index.ts` 仅导出 `AiProvider` 类 —— 业务编排层，不直接触碰 AI SDK：把应用 Provider/Model 转为配置、组装插件数组后交给 `@cherrystudio/ai-core` 的 `createExecutor` 执行。

## 6. 多窗口入口

5 个 HTML 入口共享同一 React 运行时（构建期 manualChunks 保证 reactcore 块轻量，挂件窗不连带加载 antd）：

| 入口 | 用途 |
|---|---|
| `index.html` | 主窗口完整应用 |
| `miniWindow.html` | 迷你快速助手窗 |
| `musicWidget.html` | 音乐挂件窗（经 widgetBridge 常驻 playerStore） |
| `selectionToolbar.html` | 划词悬浮工具条 |
| `selectionAction.html` | 划词动作弹窗 |

另有 `windows/mini|selection` 目录存放对应窗口的启动代码、`automation/` 存放自动化运行时（`useAutomationRunner` 等）。
