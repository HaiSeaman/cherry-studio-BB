# 01 · 项目概览

## 1. 项目定位

Cherry Studio BB 是 [CherryHQ/cherry-studio](https://github.com/CherryHQ/cherry-studio)（AGPL-3.0）的**中文单语言增强 Fork**，产品名为 `Cherry-Studio-BB`（appId: `com.kangfenmao.CherryStudioBB`），当前版本 1.9.0。

* **一句话定位**：面向生产者的一体化 AI 助手工作台 —— 对话 · 生图 · 自动化 · 效率工具 · 网络电视。

* **平台策略**：仅发布 **Windows x64**（NSIS 安装包 + Portable 便携版），上游的 macOS/Linux 打包配置已移除。

* **语言策略**：简体中文单语言分支，已移除多语言 i18n 框架。

## 2. 核心功能

| 功能                | 说明                                                                                                                                                                |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 多态 AI 助手          | 单一助手具备三种形态：`chat`（对话）、`image_gen`（生图工作区 PaintWorkspace）、`automation`(自动化任务)，HomePage 按形态动态切换工作区                                                                   |
| 对话                | 流式输出、Markdown/代码高亮（Shiki worker 流式 token 化）、MCP 工具调用、联网搜索、消息分块(Block)存储模型                                                                                         |
| 灵感生图              | 文生图/图生图，Gemini 官方宽高比与分辨率参数，生成历史侧栏                                                                                                                                 |
| 自动化任务             | 四级定时调度、系统工具分级授权、主进程 30s tick 调度器、执行简报回流                                                                                                                           |
| 效率助手（闹钟便签中控台）     | 便签 + 待办 + 闹钟 + 日历 + 本地音乐 + FM 电台六合一大卡片                                                                                                                            |
| 打卡（Habit Tracker） | 长期习惯追踪：B 风格项目行月历打卡/跳过/撤销、统计视图（完成率趋势 + 习惯对比 + **自然年统计**整年热力图）、习惯管理与 JSON 迁移；EMA 强度指数参考 Loop 思路自行实现。v1.7.4 起：月历列数随当月天数动态生成（修复非 31 天月份错位）、创建日之前的格子锁定不可点、JSON 导入带行级校验 |
| 网络电视（IPTV） | `/iptv` 独立 Tab（v1.9.0 新增）：输入 M3U（远程 URL / 本地文件）→ 自动按 `group-title` 分组 → 搜索 / 收藏 / 最近观看 → 点击即看。播放三引擎路由（HLS / 裸 MPEG-TS / MP4 原生），剧院式播放器（双击全屏、页面内最大化、滚轮调音量、音量 OSD、0-200% 增益）。数据全部本地 Dexie（v15 四张新表），与播放列表生命周期解耦的 url 快照收藏/历史 |
| 划词助手              | 系统级文本选择钩子 + 悬浮工具条 + 动作弹窗池                                                                                                                                         |
| 内嵌小程序(MinApp)     | webview 承载第三方网页应用                                                                                                                                                 |
| MCP 生态            | 9 个内置 in-memory MCP Server + 外部 stdio/SSE server 管理
| 桌面助手 · 剪贴板挂件     | 桌面助手挂件（本地音乐/FM/便签/待办/剪贴板五视图，置顶/锁定/最大化窗口控制，主题跟随）；剪贴板后台监听不限窗口开关，历史含收藏/收藏夹过滤/清空与上限双保护（收藏+置顶永不清理）/时间戳/条数与天数容量上限，多类型：文本/色号/富文本 HTML/RTF/图片原件/文件路径；**点击复制不自动置顶（同内容再次复制保留原时间与位置）**；**双击条目弹出完整内容小窗（文字可选中复制）** |

## 3. 技术栈

| 层次   | 技术                                                                         |
| ---- | -------------------------------------------------------------------------- |
| 框架   | Electron + electron-vite（三段式构建）                                            |
| UI   | React 19 + TypeScript + Ant Design 5 + styled-components + Tailwind CSS v4 |
| 路由   | react-router-dom v6（HashRouter）                                            |
| 状态   | Redux Toolkit + redux-persist（v4 迁移模型）；辅助 @tanstack/react-query            |
| AI   | Vercel AI SDK v6，自研 workspace 包 `@cherrystudio/ai-core` 封装                 |
| 本地数据 | Dexie (IndexedDB, schema v15)                                              |
| 音频   | Web Audio（音乐播放器/挂件/IPTV 音量增益）                                                        |
| 测试   | Vitest（5 个 project，3500+ 用例）+ Playwright(Electron e2e)                     |
| 规范   | oxlint → eslint → biome format 三层流水线；typecheck 用 tsgo（TS 原生预览版）            |
| 包管理  | pnpm\@10.27.0 monorepo（workspace：packages/\*）                              |
| 打包   | electron-builder（NSIS / portable），自定义 win-sign.js 签名                       |

## 5. 重要架构现状说明（V2 重构期）

仓库正处于 **V2 数据/UI 重构阶段**：

* 主进程 `ReduxService` / `StoreSyncService` 已标记 `@deprecated`（计划 v2 移除）。

* 渲染层旧 store（`store/index.ts`）与 Dexie（`databases/index.ts`）标注冻结改动，新消息模型采用 `newMessage` + `messageBlock` 分块存储。

* 侧边栏入口收敛为「聊天 + 功能页 + 设置」：音乐并入闹钟便签中控台(v2)、图片生成并入助手工作台(v3)、自动化并入助手工作台(v4)；独立 `/music`、`/paint` 路由已下线但服务保留。

* v1.7.x 起新增独立功能页「打卡」(`/habits`，Dexie v13)：与旧 store 解耦，只读/写自己的 `habits`/`habit_records` 两表，统计口径收敛在模块内纯函数。
* v1.9.0 起新增独立功能页「网络电视」(`/iptv`，Dexie v15)：纯增量追加四张表（播放列表/频道缓存/收藏快照/最近观看快照），收藏与最近观看以 **url 为主键**（与播放列表生命周期解耦，更新/删除列表不丢收藏）；播放器为模块级单例（hls.js/mpegts.js/原生三引擎），页面切换不停播。侧边栏接线共 6 处（类型/默认图标/映射/路由/label/设置页图标管理），`migrate.ts` 对老用户持久化自动补入 iptv 入口。
