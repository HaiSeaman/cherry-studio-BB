# 07 · 依赖关系

## 1. 内部模块依赖图

```
                    packages/shared (@shared 源码别名, 无 package.json)
                   IpcChannel 枚举 · 常量 · 工具函数 (main 与 renderer 共享)
                      ▲                          ▲
        ┌─────────────┴──────────┐   ┌───────────┴────────────────┐
        │      src/main (主进程)  │   │     src/renderer (渲染层)    │
        │  index.ts → ipc.ts      │   │  entryPoint → App → Router │
        │  services/*             │◀──│  pages/ store/ services/   │
        │  mcpServers/*           │IPC│  hooks/ context/ databases/│
        └─────────┬───────────────┘   └───────────┬────────────────┘
                  │            src/preload          │
                  │        (contextBridge 白名单)    │
                  ▼                                ▼
              @cherrystudio/ai-core ◀── src/renderer/src/aiCore (包装层)
              (packages/aiCore)            （仅 renderer 侧包装）
                      │
                      ▼
              Vercel AI SDK v6 (@ai-sdk/* 全家桶 + ai@6)
```

关键约束：

- **`packages/shared`** 不是 npm 包，通过 tsconfig path alias `@shared/*` 被 main / preload / renderer 三方共享；是 IPC 契约（`IpcChannel`）的唯一真源。
- **`packages/aiCore`** 是独立发布包；应用层通过 vite/tsconfig 的三个子路径别名（`@cherrystudio/ai-core/provider`、`.../built-in/plugins`、`...` 本体）直接指向 `packages/aiCore/src` 源码。
- 渲染层的 provider 配置逻辑（`aiCore/provider/providerConfig.ts`，含 HostFormatter URL 格式化）目前仅存在于 renderer 侧；主进程无对应 aiCore 目录。跨进程共享的 URL 规范化纯函数位于 `packages/shared/utils/api/`。
- 主进程 `dependencies` 不打进 bundle（electron-vite external），随 electron-builder asar 安装。

## 3. 关键第三方依赖

### 运行时（主进程 dependencies，不打包）
| 包 | 用途 |
|---|---|
| `@cherrystudio/ripgrep` | 文件目录列举加速 |
| `electron-screenshots` | 截图（原生 .node，asarUnpack） |
| `selection-hook` | 划词系统钩子（N-API prebuild，npmRebuild:false） |
| `font-list` / `node-stream-zip` / `officeparser` / `pdf-parse` / `turndown` | 字体/压缩/Office 解析/PDF 解析（v1.9.1 彻底清理 0 引用的冗余 `pdfjs-dist`）/HTML→MD |
| `jsdom` / `os-proxy-config` | DOM 解析 / 系统代理探测 |
| `uiohook-napi` | **全局键盘钩子（v1.10.0 语音输入）**：按住/松开感知（globalShortcut 感知不到 keyup）+ `keyTap` 模拟按键；N-API prebuild，`onlyBuiltDependencies` 放行 |
| `ws` | **语音识别 WebSocket 客户端（v1.10.0）**：千问需自定义鉴权请求头（`Authorization: Bearer`），Node 内置 WebSocket 不支持自定义 header |
| `koffi` | **FFI 调 `user32!SendInput`（v1.10.1 语音输入逐字上屏）**：字符走 `KEYEVENTF_UNICODE` 直达 WM_CHAR，不受物理按住的修饰键影响。**原生绑定 `@koromix/koffi-win32-x64` 是其 optionalDependency，pnpm 放在虚拟仓库里 electron-builder 收集不到**，由 before-pack.js 拷进 koffi 包内 `build/koffi/<平台>_<abi>/` 后经 asarUnpack 覆盖（见 08 文档 §4） |

| `lucide-react`、`framer-motion`、`lodash`、`shiki`、`highlight.js` | 图标/动画/工具/代码高亮 |
