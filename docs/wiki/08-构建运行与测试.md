# 08 · 构建运行与测试

## 1. 环境要求

| 项 | 要求 |
|---|---|
| Node | **>= 24.11.1**（以 `package.json engines` / `.nvmrc` 为准；README 快速开始写的 ≥20 偏旧） |
| 包管理器 | pnpm@10.27.0（`packageManager` 字段固定，可用 corepack 启用） |
| 平台 | 开发任意平台；**打包发布仅 Windows x64** |

## 2. 环境搭建与日常开发

```bash
pnpm install                # 安装依赖（含 patchedDependencies 应用）

cp .env.example .env        # .env 内容为性能/日志参数而非 API Key：
                            #   NODE_OPTIONS=--max-old-space-size=8000
                            #   CSLOGGER_MAIN_LEVEL=info
                            #   CSLOGGER_RENDERER_LEVEL=info

pnpm dev                    # 开发模式 = dotenv electron-vite dev
pnpm dev:watch              # 带 -w 监听
pnpm debug                  # --inspect --remote-debugging-port=9222 调试
```

**Windows 一键启动**：仓库根目录 `start-dev.bat` → 实际执行 `scripts/start-dev.js`：
① 探测 pnpm/npx（Windows 找 `%APPDATA%\npm\pnpm.cmd`）；② 无 node_modules 时自动首次 `pnpm install`；③ 清除 `ELECTRON_RUN_AS_NODE` 后 spawn `pnpm run dev`（支持 `--dry-run` 只做检查）。

## 3. 构建配置（electron.vite.config.ts，三段式）

### main 段
- 插件：`buildProxyBootstrapPlugin`（scripts/ 下，按 dependencies 处理代理引导）；visualizer 按需开启。
- 别名：`@main/@types/@shared/@logger`。
- 分包：**彻底禁用代码分割** —— `manualChunks: undefined` + `inlineDynamicImports: true` 强制单文件；`external` 全部 dependencies。
- sourcemap 仅 dev；生产 `legalComments:'none'`。

### preload 段
极简：仅 `@shared` 别名 + dev sourcemap。

### renderer 段
- 插件：Tailwind CSS v4、`@vitejs/plugin-react-swc`(tsDecorators)、dev-only code-inspector-plugin。
- **5 个 HTML 多入口**：index / miniWindow / musicWidget / selectionToolbar / selectionAction。
- manualChunks 精细拆 vendor：`reactcore`(react/react-dom/scheduler 单独，避免挂件窗连带加载 antd)、`vendor-antd/dexie/react/motion/highlight/lodash/redux/motion`、lucide+classnames 独立块 —— 缩短首屏解析、防挂件内存超标回归。
- target `esnext`，worker 格式 ES。

## 4. 打包发布（electron-builder.yml）

- 产品：`appId: com.kangfenmao.CherryStudioBB`、`productName: Cherry-Studio-BB`（与上游不冲突安装）；协议 `cherrystudio://`。
- 目标：仅 win 段 —— NSIS（非 oneClick、可改目录、桌面快捷方式、含 build/nsis-installer.nsh）+ portable 绿色版；签名走自定义 `scripts/win-sign.js`。
- asar files 大量排除源码/文档/测试，**关键排除 `!dist`**（否则上次 EXE 卷进 app.asar 导致体积滚雪球）；显式包含 `resources/**/*`。
- asarUnpack：`out/proxy/**`、`resources/**`、ripgrep vendor、`node-screenshots*` 原生绑定等。
- `npmRebuild: false`（selection-hook 用 N-API prebuild）；Electron 镜像 npmmirror；beforePack/afterPack/artifactBuildCompleted 挂 scripts/ 钩子。

```bash
pnpm build                  # typecheck(tsgo 三路并发 node/web/aicore) + electron-vite build
pnpm build:win:x64          # build + electron-builder --win --x64 → dist/setup.exe + portable
pnpm build:unpack           # 仅解包目录（调试打包产物）
```

## 5. 测试体系

### Vitest（vitest.config.ts，5 个 project）

| project | environment | include | setup |
|---|---|---|---|
| `main` | node | `src/main/**` | `tests/main.setup.ts` |
| `renderer` | jsdom | `src/renderer/**` | `@vitest/web-worker` + `tests/renderer.setup.ts`（过滤 tailwindcss 插件） |
| `scripts` | node | `scripts/**` | — |
| `aiCore` | node | `packages/aiCore/**` | extends 包内配置 |
| `shared` | node | `packages/shared/**` | `@shared` 别名 |

打卡模块的测试约定：`pages/habits/__tests__/stats.test.ts`（统计纯函数，含闰年/年中创建/未满年截断/空窗口边界）、`calendar.test.ts`（日期工具）、`NaturalYearStats.test.tsx`（组件：chips 排序、计数、切换、热力格子 title）、`MonthCalendar.test.tsx`（月历渲染回归：**列数=当月实际天数**、创建日锁定、今天可点/未来禁用；fake timers 固定「今天」）、`habitService.test.ts`（备份解析校验：版本/日期格式/状态枚举/引用完整性）。新增统计口径或月历边界**必须先写失败测试**（TDD），纯函数与组件分离便于断言。

全局 `globals:true`、timeout 20s、多线程 pool；coverage v8 provider。每个 project 配 benchmark include。

```bash
pnpm test               # 全部 project（--silent）
pnpm test:main|renderer|aicore|shared
pnpm test:update         # 更新 renderer 快照
pnpm test:coverage       # v8 覆盖率 (text/json/html/lcov)
pnpm bench / bench:main … # 基准测试
```

### Playwright e2e（playwright.config.ts）

- testDir `tests/e2e/specs`，专测 Electron；单 worker 串行；CI 下 forbidOnly + retry 2；globalSetup/globalTeardown；失败保留 trace/截图/视频；Page Object 模式（tests/e2e/pages/）。

```bash
pnpm test:e2e            # pnpm playwright test
```

## 7. 代码规范工具链（三层 lint 流水线）

`lint` script 顺序：**oxlint --fix → eslint --fix → typecheck → biome format**

1. **oxlint**(`.oxlintrc.json`)：第一道高速规则；typeAware；plugins unicorn/typescript/oxc/import；按目录 override env（main/scripts/playwright=node，renderer/aiCore=browser，preload 双 env）。
   - v1.7.2 起 `no-unused-vars` 开启 **`varsIgnorePattern`/`argsIgnorePattern: '^_'`**：约定「下划线前缀 = 有意忽略」（如解构剔除字段 `const { lastRunAt: _lr, ...rest }`、空实现参数 `upgradeToV13(_tx)`），避免误报（eslint.config.mjs 同步配置）。
2. **eslint**(flat config)：`@eslint/js` recommended + `@electron-toolkit/eslint-config-ts` + `@eslint-react` + react-hooks；import 排序强制；**src 下禁止裸 `console.*`（CI error），统一走 `@logger` LoggerService**；末尾关闭与 oxlint 重叠的规则去重。
3. **biome**(`biome.jsonc`)：定位格式化器（替代 prettier）：2 空格/LF/行宽 120/单引号/无分号；assist 做 JSON import 排序；linter 仅对 renderer tsx/ts 生效且只用于 Tailwind class 排序（useSortedClasses）。
4. **tsconfig 三套**：根聚合 references；`tsconfig.node.json`(main/preload)；`tsconfig.web.json`(renderer + aiCore + shared + tests mocks，paths 与 vite alias 对齐)。typecheck 使用 **tsgo**（`@typescript/native-preview`）提速。

配套 `.pre-commit-config.yaml`、`.editorconfig`。

## 8. 常见问题

| 问题 | 说明 |
|---|---|
| Node 版本不符 | engines 要求 >=24.11.1，低版本可能构建失败 |
| 打包体积异常增大 | 检查 dist 是否被卷入 asar（electron-builder.yml 的 `!dist` 过滤不可删） |
| 截图/划词功能失效 | 原生 .node 必须保持 asarUnpack；npmRebuild 保持 false |
| dev 窗口空白 | 确认 `.env` 存在（dotenv 启动依赖）；检查端口占用 |
