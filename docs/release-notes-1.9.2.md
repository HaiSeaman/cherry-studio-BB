# Cherry-Studio-BB v1.9.2 Release Notes

## 🎯 核心主题：电视页满版布局重塑（贴边 1:8:1 + 三栏可拖拽）+ 本地视频播放器 + 闹钟关铃彻底修复 + 严重崩溃修复

本版本让「电视」页脱胎换骨：播放器**贴边铺满整个窗口**（知识库式满版布局），三栏按 **1:8:1** 对齐且**可拖拽调宽**；同一播放器深度融合**本地视频播放**——拖进视频就能看，进度条/倍速/连播模式/画面旋转/断点续播一应俱全；同时彻底修复效率助手「闹钟关不掉铃声」与电视页打不开的严重问题，并完成规范轴/规格轴/过度设计轴三线并行代码审查加固。

---

## ✨ 新功能

### 1. 电视页满版布局重塑（IPTV `/iptv`）

- **满版贴边**：修复页面容器缺 `width:100%` 导致整页被压成窄条、播放器只占小空间的根因；播放器现在铺满窗口内容区，与知识库页同款满版布局
- **1:8:1 三栏对齐**：左（频道分组）10% / 中（播放器）80% / 右（播放列表）10%，比例按**百分比**记忆，任何窗口尺寸都不走样
- **三栏可拖拽调宽**：左右两根竖向拖拽手柄（悬停高亮），拖出的宽度**跨会话记住**（6%~30% 夹取保护，播放器永远占大头）
- 控制条「页面内最大化」保留：一键隐藏两侧纯看片，Esc 还原

### 2. 本地视频播放器（与 IPTV 同屏融合，原生引擎方案）

- **右栏双 Tab**：「电视台 / 本地视频」自由切换；「添加本地视频」按钮支持一次多选，同一文件重复添加自动去重（Dexie v16 新表 `iptv_locals`，纯追加无存量迁移）
- **拖拽入片自动播放**：把视频文件拖进播放器，松手即加入列表并立刻开播（悬停有虚线高亮提示）
- **腾讯视频式控制条**（播本地视频时展开，看直播自动收敛为精简模式）：
  - **进度条拖动跳转** + 当前时间 / 总时长显示（拖动中滑块只跟手指，松手才 seek，不和播放位置打架）
  - **上一个 / 下一个**视频（列表首尾环绕）
  - **倍速菜单**：0.5x ~ 3x，偏好跨会话记住
  - **播放模式**：顺序播放 → 单曲循环 → 随机播放，循环切换；播完自动按模式接下一部（顺序播到末尾自然停止）
  - **画面旋转**：顺时针 90°，点一次转一次（90°→180°→270°→回正），旋转后自动缩放适配屏幕，换片自动复位
  - **截图**：一键保存当前画面 PNG；**画中画**：小窗置顶观看
- **断点续播**：播放中每 3 秒自动存档，重新打开超过 5 秒且未临近片尾的视频自动从上次位置继续（带提示），列表项显示「已看 X / Y」进度
- **键盘快捷键**：空格播放/暂停、←/→ 快退快进 5 秒、↑/↓ 音量 ±10（输入框内不误触）
- **架构克制（资源零负担）**：本地文件强制走浏览器原生解码引擎、失败不自动重连（文件不会自己好，重试按钮留给手动）；与直播共用同一个 video 元素，同一时刻只有一个解码器；**零新增依赖、安装包零增大**
- 格式能力：MP4 / MOV / MKV（主流编码）/ WebM / TS 直接播放，H.265 走显卡硬解；AVI / RMVB / WMV 等老格式不支持（会给出明确提示而非黑屏）

## 🐛 修复

### 效率助手：闹钟「关不掉铃声」（三重根因逐个击破）
- 点「关闭闹钟」后自动"接着响下一个排队的" → 现在点一次**整批清空、立刻安静**（横幅按钮与面板卡片按钮双通道同样生效）
- 同一闹钟在 90 秒补触发窗口内每秒重复入队（页面数据未回流时永不停止）→ 触发标记**立即合并进内存**，与页面刷新解耦
- 音频环境异常导致停止流程卡死 → 全链路容错；停止时立即静音主增益，消除约 1.2 秒余音

### 电视页严重崩溃（老存档缺新字段）
- 修复打开电视页报 `Cannot read properties of undefined (reading 'icon')` 无法使用：redux-persist 装回老存档时整体替换设置切片，新增字段缺失成 undefined → 接入 `mergeDefaults` 启动补默认值机制（与 shortcuts 同套路，未来新增字段自动愈合），控制条防御式查表 + 倍速防非数字双保险

### 其他
- 修复启动时序竞争：存档装回完成后同步栏宽占比，「拖拽调宽跨会话记住」不再被默认值覆盖
- 修复拖拽手柄在拖动中途组件卸载的监听器泄漏
- 修正 3 个历史遗留坏测试（对齐实现的既有正确语义：吞错记日志、数组清空即删 key 防内存泄漏）
