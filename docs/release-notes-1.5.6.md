# Cherry-Studio-BB v1.5.6 Release Notes

> 版本：1.5.6 · 发布日期：2026-08-21

本次版本聚焦**桌面挂件体验升级**：把「音乐挂件」和「便签待办挂件」合并为一个「桌面助手」小窗口，四模块一键切换；本地音乐视图新增收藏按钮。

## ✨ 新功能

### 1. 桌面助手：四模块合并小窗口
- 音乐挂件（本地音乐 + FM 电台）与便签挂件（便签 + 待办）**合并为一个桌面小窗口**。
- 窗口头部提供 **4 个图标按钮**：本地音乐 / FM 电台 / 便签 / 待办，点击即切换，当前模块高亮。
- **窗口自动适配**：切到音乐视图窗口紧凑（380×220），切到便签/待办视图自动变高（320×480），手动拉伸后按各视图分别记忆尺寸。
- 数据与主程序完全打通：便签/待办实时双向同步、本地音乐/FM 遥控播放，关闭/打开挂件不打断音乐。
- 侧边栏、托盘、设置页入口统一为「桌面助手」，开机自启兼容老配置。

### 2. 本地音乐收藏按钮
- 本地音乐视图的**歌曲名右侧新增 ☆/★ 收藏按钮**，点击一键收藏/取消收藏当前曲目。
- 收藏状态与主程序音乐页**实时双向同步**；「收藏夹播放模式」下取消收藏当前曲，播完后自动落回收藏池，行为与主窗口完全一致。

## 🛡️ 稳定性

- 便签草稿防丢机制原样保留：切视图/关闭窗口不丢字（四视图常驻挂载 + CSS 切换，杜绝卸载打断防抖）。
- 收藏写入收敛为单一数据源（主窗口 bridge 统一处理），杜绝挂件与主窗口状态不一致。

## 🧪 质量

- Renderer 全量测试 **164 文件 / 2817 用例全部通过**；主进程 309、共享层 96 用例通过。
- TypeScript typecheck（node + web + aiCore）与 ESLint 零错误。
- 完整构建验证通过：挂件入口 bundle 仅 32.6KB，无 antd 混入，内存不回归。

## 📦 下载

- Windows 安装包（NSIS）：`Cherry-Studio-BB-1.5.6-win-x64-setup.exe`
- Windows 便携版（Portable）：`Cherry-Studio-BB-1.5.6-win-x64-portable.exe`

## ⚠️ 已知事项

- 老版本开启过「便签挂件」或「音乐挂件」开机自启的用户，升级后合并挂件会保持开机自启。
- 便签挂件独立窗口已移除（功能并入桌面助手），原 `sticky-widget-state.json` 位置记忆不再使用。
