# Cherry-Studio-BB v1.10.2 Release Notes

## 🎯 核心主题：FM 电台全面改版 —— 「国内 / 国外 × 综合 / 音乐」四大板块，121 台精选电台内置，CCTV / 香港电台 / NHK 等 m3u8 直播流现在能听了

这次把效率助手里那块 FM 电台整个重做了。以前是「热门 + 中港音乐」两个标签页、每次打开都要联网去公共电台库现拉，网不好就一片空白。现在改成 **四大板块**（国内 / 国外 各含 综合 / 音乐），**121 台精选电台直接打包进应用**，断网也能听；更重要的是，以前完全放不出来的 **m3u8 直播流（CCTV 系列、香港电台、NHK、KBS 等 31 台）现在可以正常播放**。

其余功能（聊天、生图、视频、自动化、打卡、电视、便签闹钟）行为完全不变。

---

## ✨ 新增与改进

### 1. FM 电台改成四大板块，一眼就能找到想听的

- 一级分类：**国内 / 国外 / 搜索 / 收藏**
- 「国内」「国外」下再分 **综合 / 音乐** 两个子板块，共四个板块，切换标签页即可
- 每个子板块标签上直接显示台数，不用点进去猜

### 2. 121 台精选电台内置，断网也能听

- 国内综合 30 台、国内音乐 31 台、国外综合 30 台、国外音乐 30 台
- 覆盖：央视系列与央广 / CRI / CGTN、各地省市广播、香港电台与商业电台、台湾地区与境外华语台，以及 CNN / NPR / BBC 系 / RFI / 德国之声 / NHK / KBS / 新加坡电台等
- 以前依赖公共电台库在线拉取，**服务器抽风就打不开**；现在电台清单随应用下发，**零网络依赖**

### 3. 电台列表更好看了

- 台名自动拆成主标题 + 副标题，长名字不再被截断得莫名其妙
- 每个电台带一个**地区 / 风格徽标**（国家台、香港、怀旧台、巴洛克、蒸汽波……），扫一眼就知道是什么调性
- 每个电台带**一句话简介**和编码格式（MP3 / HLS / AAC）

### 4. m3u8 直播流现在能播了（本次最关键修复）

- 精选清单里有 **31 台是 m3u8 直播流**，包括 CCTV-1 / CCTV-13 / CCTV-15、香港电台、商业电台 881、NHK Radio 1、KBS、BFM 等
- 这类流以前**在应用里根本放不出来**，旧实现干脆把它们过滤掉了 —— 等于把国家级电视/电台直播源全丢了
- 现在接入 HLS 播放引擎（和「网络电视」功能同一套方案），这些台**点击即播**
- 其中香港电台、商业电台这类**网址里不带 `.m3u8` 字样**的流做了专门识别，不会再漏判

### 5. 搜索、收藏、自定义电台照旧

- 搜索页能力不变：按**名称 / 国家 / 标签**三种模式搜全球电台
- 收藏、自定义电台、隐藏不喜欢的台：操作方式和以前完全一样
- 自定义电台会自动并入四个板块列表的末尾，方便随时找到

### 6. 修掉几个小毛病

- **自定义电台删不掉**：如果自建电台的地址和内置电台重复，删除键会失效、只能"隐藏"。现在能正常删除了
- **子板块的台数显示不准**：以前显示的是内置数量，不扣除你隐藏掉的、也不含自建的。现在显示的是**真实可听数量**
- **搜索时切板块会被转圈挡住**：现在转圈只在搜索页出现，切到板块页立刻能看到列表

## ⬆️ 升级说明

- 直接覆盖安装即可，**用户数据与设置完全兼容**：收藏的电台、自定义电台、音量、播放模式全部原样保留
- 首次打开 FM 电台即是四大板块，无需任何设置
- 断网状态下四大板块仍可正常收听（本来就内置在应用里）；只有「搜索」页需要联网
- 若某个台播放失败，应用会自动跳到下一台；个别境外源可能因网络环境无法访问，属于正常现象
