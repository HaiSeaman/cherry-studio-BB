# Cherry-Studio-BB v1.11.5

> **桌面助手挂件新增「天气」TAB —— 打开就能看本地天气，不用注册、不用申请任何 API Key。**

---

## 🌤️ 这次更新带来了什么

桌面右下角那个常驻的小挂件，顶栏图标从 5 个变成 **6 个**，最左边多了一个天气：

```
[🌤 天气] [📋 剪贴板] [🎵 本地音乐] [📻 FM 电台] [📝 便签] [☑ 待办]
   ↑ 新增，就在剪贴板左边
```

点一下就能看天气，再点一下切回剪贴板，和以前一样顺手。

---

## 天气页能看什么

**现在**：大号温度 + 体感温度 + 天气图标、今天最低最高温、降水概率，以及一整排详细数据 —— 湿度、风向风速、气压、云量、阵风、降水量。

**今天**：日出、日落、紫外线强度（从「低」到「极高」分级）。

**未来 5 天**：每天一行 —— 星期、天气图标、天气文字、温度区间、降雨概率。

**空气质量**：PM2.5、PM10、AQI 数值，以及等级（优 / 良 / 轻度污染 / 中度 / 重度 / 严重污染）。

---

## 定位：自动猜，也能手动选

**第一次打开**会自动用 IP 大致判断你在哪个城市，直接显示天气。

如果猜得不准（IP 定位只到城市级，有时会偏），点右上角的**放大镜图标**，输入城市名就行：

- 支持中文，比如输入「杭州」
- 同名城市会显示省份区分：「杭州 · 浙江」「杭州 · 四川」
- 选中后**自动记住**，下次打开直接用，不用再选

> 💡 建议：第一次用的时候手动选一次你的城市，之后就一直准了。

## 断网也不会白屏

- **天气接口失败**：显示上次的数据 + 顶部提示，点刷新可重试
- **空气质量接口失败**：只隐藏那一行，不影响主天气
- **请求太慢**：8 秒自动超时，不会一直转圈
- **反复切换城市**：30 分钟内同一城市走缓存，不重复请求

## 隐私说明

- **天气面板第一次点开才会联网**。你不点它，程序不会发起任何定位或网络请求
- IP 定位会把你的 IP 发给 `ipwho.is`。不想暴露的话，可以用「手动搜索城市」，不要点「使用当前位置」

## 已知限制（如实说明）

1. **IP 定位只到城市级，可能不准** —— 这是 IP 定位本身的限制（运营商出口 IP 可能归属别处），不是程序问题。手动选一次城市就能永久记住
2. **天气依赖网络** —— 完全离线时只能显示上次缓存的数据
3. **Open-Meteo 免费额度面向非商业用途** —— 个人自用完全足够；商业使用需自行购买其订阅
