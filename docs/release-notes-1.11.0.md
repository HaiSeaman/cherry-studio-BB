# Cherry-Studio-BB v1.11.0 Release Notes

## 🎯 核心主题：移除「电视」（IPTV）TAB，专注「AI 助手 · 生图 · 自动化 · 效率」四大工作台

这一版做的是「减法」。

**「电视」TAB 已整体移除**：侧边栏不再有电视图标，电视页面、播放器、频道管理、收藏与最近观看、本地视频播放等全部功能，连同它们的代码一起删掉了；两个只服务于电视的第三方库（`mpegts.js`、`iptv-playlist-parser`）也已卸载。

**为什么移除**：电视（IPTV）需要自己准备 M3U 直播源，源本身又常常失效、需要手动更新，维护成本和实际使用频率不成正比。把它拿掉之后，**安装包更小、启动更轻、后台更干净**。

**移除是彻底的**：老版本升级上来后，侧边栏残留的「电视」图标会自动消失；数据库里电视专用的 5 张表会被安全删除（**不会动其他任何数据**）。

> ⚠️ **请注意**：电视功能保存过的数据 —— **播放列表、收藏频道、最近观看、本地视频列表与播放进度** —— 会随功能下架**永久清空、无法恢复**。如果你还需要这些数据，请先自行记录，或暂时不要升级。

除「电视」外，其余功能（AI 对话 / 灵感生图 / 自动化任务 / 效率助手（便签·待办·闹钟·日历·本地音乐·FM 电台）/ 习惯打卡 / 小程序 / 全局语音输入 / 划词助手 / 桌面挂件）**行为完全不变**。

## 🧹 本次改动

### 1. 「电视」TAB 整体下线

- 侧边栏入口、独立路由、整套电视页面与播放内核全部删除
- 专用依赖卸载：`mpegts.js`（裸 MPEG-TS / FLV 播放）、`iptv-playlist-parser`（M3U 解析）
- **`hls.js` 保留** —— FM 电台里的 m3u8 直播流仍在用它播放，收音机功能完全不受影响
- 老用户升级路径已做保护：侧边栏配置自动迁移，把残留的「电视」图标从「显示 / 隐藏」两个列表里清除；数据库做一次结构升级整表删除 5 张电视表

### 2. 顺手清理的死代码

- 删掉两个早已无人引用的导出（一个「必显图标」常量、一个「向后兼容」的转发导出）
- 修掉一处会让代码规范检查整体失败的导入排序错误

### 3. 开发者文档同步

- Wiki 五篇文档 + 索引页逐条纠正：删除所有指向已不存在的电视功能、电视路由、电视数据表、电视测试目录的描述
- 依赖关系、Dexie 数据库版本、持久化迁移版本号全部更正到与实际代码一致

- 直接覆盖安装即可。聊天记录、助手、模型配置、便签、待办、闹钟、日历、音乐、打卡、小程序设置等**用户数据完全兼容**，无需任何手动操作

- 不需要重新登录，也不需要重新配置任何服务商或 API Key
