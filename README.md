## 📖 项目简介

Cherry-Studio-BB 是一个桌面端 AI 助手，基于 Electron + React 构建，支持接入任意 OpenAI 兼容 API 与 Gemini 官方 API。采用**无边框窗口 + 右侧导航栏**界面，1.5.0 起将分散的功能页聚合为「**两大中枢 + 两个扩展入口**」，操作更集中、界面更统一：

- 🤖 **AI 助手工作台**（默认主页）：左侧「AI 助手」TAB。支持 3 种助手形态一键创建——💬 对话 / 🎨 生图 / ⚡ 自动化，右侧按类型动态挂载专属工作区。生图带左侧生成历史，自动化带任务面板（每周/每天/间隔/一次性定时、输出目录、指定文件、执行简报回流）
- 📋 **效率助手工作台**：「效率助手」导航入口。便签 + 待办 + 闹钟 + 日历 + 本地音乐 + FM 电台六合一大卡片，四宫格布局，操作全部收拢在一页
- 🧩 **小程序** / ⚙️ **系统设置**：保持独立沉浸式体验

> 本项目为**单语言中文分支**：界面与文案全部为简体中文，未引入多语言方案。

## 🚀 快速开始

### 环境要求
- Node.js ≥ 20
- pnpm ≥ 9

### 安装与开发

```bash
# 安装依赖
pnpm install

# 类型检查
pnpm typecheck

# 运行开发模式
pnpm dev

# 运行测试
pnpm test

# Lint
pnpm lint
```

### 构建打包（Windows x64）

```bash
pnpm build:win:x64
```

产物输出至 `dist/`：
- `Cherry-Studio-BB-<version>-x64-setup.exe`（安装版）
- `Cherry-Studio-BB-<version>-x64-portable.exe`（绿色版）

## 📖 使用说明

### 切换主题
1. 打开「设置 → 显示设置」
2. 在「主题」区域选择 6 款主题之一（晨间绿洲/浅蓝晴空/浅粉蔷薇/浅黄晨光/深灰暮色/深蓝夜色），即时生效
3. 主题切换后全应用（含音乐/闹钟便签工作台）配色统一跟随

### 配置模型服务商
1. 打开「设置 → 模型服务」
2. 添加 API 服务商（OpenAI 兼容地址 + API Key），或启用内置服务商
3. 添加/勾选所需模型，**打开服务商启用开关**（未启用的服务商不会出现在任何模型列表中）

### 使用 AI 绘画（灵感生图助手）
1. 点击右侧导航栏「AI 助手」，左侧「新建助手」选「🎨 灵感生图」
2. 选择模型（仅显示已启用服务商中的视觉/绘画模型）
3. 输入提示词，通过参数胶囊栏选择比例/分辨率/张数
4. 点击「生成图片」，生成中可点「停止生成」
5. 生成结果自动保存；左侧「生成历史」可切换/删除每次会话，最新缩略图即时呈现

### 使用自动化任务（自动化助手）
1. 「新建助手」选「⚡ 自动化任务」，在右侧任务面板点「新建任务」
2. 设置触发方式（**每周**选星期+时间 / 每天 / 间隔 / 一次性）、任务指令，勾选工具授权
3. 「输出目录」选本地文件夹（AI 生成文档保存处）；「指定文件」选要读写修改的本地文件
4. 保存后按调度自动执行；右栏「运行历史」看时间线，每次结果自动写入助手「运行日志」话题（执行简报）

### 使用音乐工作台（效率助手）
1. 点击右侧导航栏「效率助手」，左下角**一体化音乐卡片**（本地音乐 / FM 各占一半）
2. **本地音乐**：点「添加音乐」选文件或「文件夹」递归扫描；底部播放舱切模式/拖进度/收藏
3. **FM 电台**：默认「中港音乐」页；播放舱左侧换台/播放、右侧音量/刷新、下方状态栏显示电台与实时网速
4. 本地与 FM 互斥播放：开电台自动停本地，反之亦然；切走页面后台继续播放

### 使用效率助手（便签/待办/闹钟/日历）
1. 点击右侧导航栏「效率助手」（四宫格：便签待办 / 闹钟 / 音乐 / 日历）
2. **便签 + 待办**：左上格左侧便签列表（3），右侧内容区上=便签编辑器、下=待办事项（4:6）
3. **便签**：右上「历史」恢复任意历史版本，「长图」复制到剪贴板，「预览」切换 Markdown 渲染
4. **闹钟**：三个独立内容页——倒计时 / 定时闹钟 / 日历闹钟；「＋ 自定义声音…」可选电脑里的 MP3
5. **日历**：点日期 → 左侧设当日闹钟，右侧写当日待办；闹钟响铃切到其他页面也照响 + 系统通知

### 数据与备份
- 设置 → 数据设置：可自定义图片保存路径、数据备份/恢复（兼容上游备份格式）
- 音乐曲库/便签/待办/闹钟/日历数据存于 IndexedDB，随应用数据目录迁移

## 🧩 与上游 Cherry Studio 的差异

本项目在保留上游全部核心能力的基础上做了以下定制：

1. **多态 AI 助手工作台**：对话 / 生图 / 自动化三形态 + 三模板创建向导，右侧按类型动态挂载工作区（聚合原聊天 / 绘画 / 自动化三入口）
2. **灵感生图助手**（原独立绘画页）：文生图 / 图生图、Gemini 参数、参数胶囊、**左侧生成历史列表**、重新/停止生成、提示词优化、自动保存
3. **自动化任务助手**：四级定时（每周/每天/间隔/一次性）、系统工具分级授权、**输出目录 + 指定文件**、执行简报卡片回流运行日志、主进程调度独立
4. **效率助手工作台**（原闹钟便签 + 音乐合并）：便签+待办合并、闹钟、日历、本地音乐、FM 电台六合一大卡片四宫格
5. **音乐一体化卡片**：本地 / FM 5:5 并排 + 分隔线，两个播放舱高度对齐、控制键同水平线；FM 状态栏内嵌播放舱
6. **6 款护眼主题系统**：浅色 4 款 + 深色 2 款，设置一键切换，工作台页面跟随主题变色（自绘设计系统基于 CSS 变量）
7. **无边框窗口 + 毛玻璃**：顶部无栏条、内容顶满，右侧 50% 透明毛玻璃导航栏，窗口控制键内置导航栏；晨雾丙烯酸背景 + 弹窗毛玻璃化
8. **单语言中文化**：移除多语言框架，界面硬编码简体中文
9. **精简清理**：侧边栏 7 入口收敛为 4（AI 助手 / 效率助手 / 小程序 / 设置），删除旧独立路由与页面外壳
10. **产品名**：Cherry-Studio-BB（`productName`/`appId` 独立，不与上游安装冲突）
11. **Windows x64 专属 + 资源优化**：仅面向 Windows x64 构建发布（移除 macOS/Linux/arm64 配置）；隐藏窗口懒创建、主进程按需加载、后台节流、小程序闲置回收（v1.4.0）

### v1.4.0 —— 常驻内存大幅下降
**本次版本核心：资源占用优化重构。** 不动界面、不动操作习惯，专注降低常驻内存与后台资源消耗。实测内存峰值 **约 1.35GB → 约 0.8GB（约 -40%）**，后台挂机 CPU 占用同步下降。

**为什么能省这么多**：旧版启动后会在后台常驻 4 个隐藏渲染进程（迷你窗口预加载 + 划词助手工具栏 + 划词动作窗口 + 系统保留渲染器），合计约 580MB。本次将大部分改为「首次用到时再创建」。

**删预加载窗口（省 ~500MB）**
- 快捷助手迷你窗口改为首次唤出时创建（首唤慢约 0.5 秒，之后复用无感）——该预加载原本只为规避 macOS 窗口问题，Windows 上纯属浪费
- 划词助手工具栏 + 动作窗口改为首次划词时创建（首次慢约 0.5 秒，之后复用）

**主进程瘦身（省 ~50-80MB）**
- 删除 93 行死代码 `@napi-rs/canvas` DOMMatrix polyfill（主进程从未加载 pdf-parse），连同依赖与打包配置移除
- `officeparser`、`jsdom` 改为按需动态加载，不再随启动常驻
- 删除本地崩溃收集器 `crashReporter`，常驻 crashpad 进程（约 39MB）不再拉起

**后台节流恢复**
- 移除 `backgroundThrottling: false`（1.0 模板遗留）：最小化/隐藏到托盘后恢复定时器节流，后台 CPU 下降；闹钟 90 秒补触发窗口兜底、音频页面不受节流影响

**小程序闲置回收**
- 后台小程序闲置 30 分钟自动销毁其 webview 进程（约 300MB/个），重开自动恢复页面；正在播放音频/视频的（如后台听歌）永不回收

**验证**
- `typecheck` 通过；3506 项测试全绿；构建产物确认动态依赖正确分包
- 进程数由 9 个降至约 5 个

## 📁 项目结构（简）

```
├── src/
│   ├── main/            # Electron 主进程（窗口/AutomationService 调度/文件/服务/IPC）
│   ├── preload/         # 预加载脚本（window.api 桥接）
│   └── renderer/        # 渲染进程（React 应用）
│       ├── pages/
│       │   ├── home/        # ★ AI 助手工作台（Chat + PaintWorkspace + AutomationWorkspace，按助手类型分发）
│       │   ├── paint/       # 灵感生图组件（PaintContent/PaintInputbar/PaintHistoryList，被工作台复用）
│       │   ├── music/       # 音乐组件（本地播放器 + FM 电台，被效率助手并入）
│       │   ├── notes/       # ★ 效率助手工作台（便签/待办/闹钟/日历/音乐一体四宫格）
│       │   ├── automation/  # 自动化组件（被 AutomationWorkspace 吸收，页面外壳已删）
│       │   └── settings/    # 设置页
│       ├── automation/  # 自动化执行器（runner.ts + 系统工具）
│       ├── aiCore/      # AI 调用封装（Provider 配置/参数构造）
│       ├── services/    # 业务服务（消息流/数据库/备份）
│       └── store/       # Redux 状态管理
├── packages/
│   ├── aiCore/          # 自研 AI 运行时（RuntimeExecutor/插件体系）
│   └── ai-sdk-provider/ # AI SDK Provider 适配
├── resources/           # 运行时资源（隐私页/二进制）
└── electron-builder.yml # 打包配置
```
