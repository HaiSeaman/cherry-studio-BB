## 📖 项目简介

Cherry-Studio-BB 是一个桌面端 AI 助手，基于 Electron + React 构建，支持接入任意 OpenAI 兼容 API 与 Gemini 官方 API。1.2.0 起采用**无边框窗口 + 右侧导航栏**的全新界面，内置四个独立工作台页面：

- 💬 **AI 聊天**：多模型对话、流式输出、MCP 工具、划词助手
- 🎨 **AI 绘画工作台**：独立的图片生成页面，支持文生图、图生图、Gemini 官方参数、历史会话管理
- 🎵 **音乐工作台**：本地音乐播放器 + FM 网络电台（左播放器 / 右电台双栏）
- ⏰ **闹钟便签工作台**：便签 + 待办 + 闹钟 + 日历四合一（2×2 四宫格，闹钟与日历联动）
- 🔌 **多服务商接入**：OpenAI 兼容接口、Google Gemini、Ollama 本地模型等
- 🧩 **扩展生态**：小程序、MCP 服务器、WebDAV/S3 云备份

> 本项目为**单语言中文分支**：界面与文案全部为简体中文，未引入多语言方案。

## 🚀 快速开始

### 环境要求
- Node.js ≥ 20
- pnpm ≥ 9

### 安装与开发

```bash
# 安装依赖
pnpm install

# 类型检查
pnpm typecheck

# 运行开发模式
pnpm dev

# 运行测试
pnpm test

# Lint
pnpm lint
```

### 构建打包（Windows x64）

```bash
pnpm build:win:x64
```

产物输出至 `dist/`：
- `Cherry-Studio-BB-<version>-x64-setup.exe`（安装版）
- `Cherry-Studio-BB-<version>-x64-portable.exe`（绿色版）

## 📖 使用说明

### 切换主题
1. 打开「设置 → 显示设置」
2. 在「主题」区域选择 6 款主题之一（晨间绿洲/浅蓝晴空/浅粉蔷薇/浅黄晨光/深灰暮色/深蓝夜色），即时生效
3. 主题切换后全应用（含音乐/闹钟便签工作台）配色统一跟随

### 配置模型服务商
1. 打开「设置 → 模型服务」
2. 添加 API 服务商（OpenAI 兼容地址 + API Key），或启用内置服务商
3. 添加/勾选所需模型，**打开服务商启用开关**（未启用的服务商不会出现在任何模型列表中）

### 使用 AI 绘画
1. 点击右侧导航栏「图片生成」图标
2. 选择模型（仅显示已启用服务商中的视觉/绘画模型）
3. 输入提示词，选择尺寸/分辨率
4. 点击「生成图片」，生成中可点「停止生成」
5. 生成结果自动保存，历史会话可在左侧查看

### 使用音乐工作台
1. 点击右侧导航栏「音乐」图标
2. **本地音乐**：点「添加音乐」选文件或「文件夹」递归扫描，列表即出封面/艺术家；底部播放舱可切模式、拖进度、收藏
3. **FM 电台**：默认「中港音乐」页第一项就是清晨音乐台；顶部 LIVE 胶囊显示实时网速；「+ 自定义」可添加任意流地址
4. 本地与 FM 互斥播放：开电台自动停本地，反之亦然；切走页面后台继续播放

### 使用闹钟便签工作台
1. 点击右侧导航栏「闹钟便签」图标（2×2 四宫格：便签/闹钟/待办/日历）
2. **便签**：右上「历史」可恢复任意历史版本，「长图」复制到剪贴板，「预览」切换 Markdown 渲染
3. **闹钟**：三个独立内容页——倒计时 / 定时闹钟 / 日历闹钟；铃声下拉底部「＋ 自定义声音…」可选电脑里的 MP3
4. **日历**：点日期 → 左侧设当日闹钟（会出现在闹钟页的「日历闹钟」内容页并统一响铃），右侧写当日待办（独立于便签/待办）
5. 闹钟响铃时即使切到其他页面也会响 + 系统通知 + 自动唤起窗口

### 数据与备份
- 设置 → 数据设置：可自定义图片保存路径、数据备份/恢复（兼容上游备份格式）
- 音乐曲库/便签/待办/闹钟/日历数据存于 IndexedDB，随应用数据目录迁移

## 🧩 与上游 Cherry Studio 的差异

本项目在保留上游全部核心能力的基础上做了以下定制：

1. **新增 AI 绘画工作台 TAB 页**（上游仅有聊天内生成图片工具）
2. **新增音乐工作台 TAB 页**（本地播放器 + FM 电台，RadioBrowser 全链路中文电台）
3. **新增闹钟便签工作台 TAB 页**（便签/待办/闹钟/日历四合一，闹钟日历联动）
4. **Gemini 官方图像参数支持**（宽高比/分辨率/人物模式，模型感知传参）
5. **绘画体验增强**：重新生成、停止生成、提示词编辑重生成、尺寸预设扩展、自动保存
6. **6 款护眼主题系统**：浅色 4 款 + 深色 2 款，设置一键切换，工作台页面跟随主题变色（自绘设计系统基于 CSS 变量）
7. **无边框窗口 + 毛玻璃**：顶部无栏条、内容顶满，右侧 50% 透明毛玻璃导航栏，窗口控制键内置导航栏；晨雾丙烯酸背景 + 弹窗毛玻璃化
8. **单语言中文化**：移除多语言框架，界面硬编码简体中文
9. **精简清理**：移除与中文用户无关的功能与历史遗留代码（含旧顶部导航/旧 TAB 容器）
10. **产品名**：Cherry-Studio-BB（`productName`/`appId` 独立，不与上游安装冲突）

## 📁 项目结构（简）

```
├── src/
│   ├── main/            # Electron 主进程（窗口/文件/服务/IPC）
│   ├── preload/         # 预加载脚本（window.api 桥接）
│   └── renderer/        # 渲染进程（React 应用）
│       ├── pages/
│       │   ├── home/        # AI 聊天页
│       │   ├── paint/       # ★ AI 绘画工作台
│       │   ├── music/       # ★ 音乐工作台（本地播放器 + FM 电台）
│       │   ├── notes/       # ★ 闹钟便签工作台（便签/待办/闹钟/日历）
│       │   └── settings/    # 设置页
│       ├── aiCore/      # AI 调用封装（Provider 配置/参数构造）
│       ├── services/    # 业务服务（消息流/数据库/备份）
│       └── store/       # Redux 状态管理
├── packages/
│   ├── aiCore/          # 自研 AI 运行时（RuntimeExecutor/插件体系）
│   └── ai-sdk-provider/ # AI SDK Provider 适配
├── resources/           # 运行时资源（隐私页/二进制）
└── electron-builder.yml # 打包配置
```
